## 작품의 마침표

EP12는 12부작 〈언리얼 아이돌〉의 윤리적 마침표이자 EP1과의 완전한 미러링 회차다. 시청자가 카타르시스가 아닌 잔잔한 책임감을 가지고 작품을 닫게 한다. 빌보드 1위 무대에서 「뉴」를 위한 자리를 비우고 시아의 원본 보컬을 헌정 — 1년 후 도윤이 잔여 캐시 파일을 클릭하지 않고 닫는다.

- 비트 1 (S#1~S#6) — 백스테이지 + 김리아의 첫 얼굴 노출
- 비트 2 (S#7~S#12) — 마지막 무대 1부 〈Unreal〉 + 〈Light Particle〉. 빛 입자 효과 부재
- 비트 3 (S#13~S#24) — 마지막 무대 2부 〈Echo Forever〉 14분 풀버전. 시아 원본 보컬 + 7인 라이브 화음 + 김리아 무대 등장
- 비트 4 (S#25~S#27) — ECHO 공식 종료 선언

## 작가적 약속 5개 (회차 시그니처)

1. **마지막 무대의 빈자리** — 7명만 무대에 오른다. 「뉴」를 위한 자리에 핀스폿만. 〈Light Particle〉의 빛 입자가 켜지지 않는다. 부재의 시각화
2. **시아의 원본 보컬 사용** — AI 합성 없이. 라이브 데모의 살짝 거친 음질. 14분 무대 정점. *"이 곡은 시아 본인의 미발표 자작곡 데모입니다"*의 명시
3. **김리아의 얼굴 첫 정면 노출 (3단)** — S#3 (분장실 거울) → S#22 (무대 정면) → S#44 (다큐 인터뷰 클로즈업)
4. **도윤의 잔여 캐시 파일 결단** — 3컷 정밀 시퀀스(마우스/화면/얼굴). 클릭하지 않고 닫는다. EP1 시아에게 한 "나중에 듣자"의 1년 후 변주 — 이번엔 "나중에 듣지 않는다"
5. **EP1과의 완전한 미러링** — 시아 어머니 흐느낌(EP1) → 미소(EP12) / 무대 위 8명(7+「뉴」) → 7명 + 김리아 자기 얼굴 / NEU 학습 세션 종료 자막 → 잔여 캐시 동기화 알림 / CCTV 한강 다리(EP1 04:17) → 새벽 푸른 한강 다리(EP12 04:17~) / 도윤 빈 가슴 안주머니 → 시아의 사인 종이 넣고 1년 후 만지지 않음

## 「뉴」의 학습/미학습 비율

— / — (트리트먼트 명시). 「뉴」가 무대에서 사라진다. 비율을 더 이상 말할 수 없음. 잔여 캐시 파일이 "미해결 50%"의 영원한 자국. EP12에서 「뉴」는 무대 위에 등장하지 않으며, 그 부재의 자리(핀스폿) 안에서 시아의 빛 입자가 *4초만* 형태 없이 흩어진다. 도윤의 잔여 캐시 파일 결단으로 「뉴」 프로젝트는 공식 종료.
