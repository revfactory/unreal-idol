회차 작가적 약속 (5개)

1. **Unsent 무대 4부 구조의 무게 비율 정확** — 1절 30% · 브릿지 25% · 2절 15% · 후렴 20% · 마지막 음 10% 합계 100%. 비트 6 안에서 카메라 워크가 시드 1-5 준수(슬로 클로즈업 → 핸드헬드 객석 → 부스 정밀 컷 → 7인 4초씩 → 부감 침묵).
2. **김리아의 정면 얼굴 노출은 S#38(2절)에서 처음** — 1-8회 동안 거울 반사·헬멧·뒤모습으로만 보였던 김리아의 얼굴이 2절 후반에서 정면 첫 노출. SP-021 본 회수의 첫 단계. 부산 사투리 *마, 진짜로 진짜로*의 시그니처 자기 인지.
3. **「뉴」의 빛 입자 흩어짐 + 일부가 무대에 남음(S#43)** = EP1과 의도된 변주. EP1에서는 입자가 *모두* 흩어졌으나 EP9에서는 *한 줄기가 남는다* — 시청자가 무의식적으로 *이번엔 무언가 다르다*를 느끼게.
4. **한유진의 인터뷰 결단(S#54)** = SP-005(시아 사고 직전 통화) 1차 회수의 직접 빌드업. 5개월 침묵의 첫 균열이 *내일 — 인터뷰해주세요*의 7어절로 압축.
5. **회차 클리프행어 — 도윤의 *진우가 우리 학습 모델에 접근하려 했어*** — 정보 공개 + 만남 임박 + 미스터리 심화 복합형. 한유진 라인과 도윤 라인 두 외부 라인이 동시에 EP10-11의 결단을 부른다.
