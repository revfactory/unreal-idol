## 회차 작가적 약속 5개

1. **발견의 도미노 — 카탈로그가 되지 않는 호명 연쇄**
   비트 1 → 2 → 3 → 4 → 5의 5개 발견이 *한 발견이 다음을 호명하는* 연쇄. 비트 1의 미발송 메시지가 비트 3의 손편지 공개를 끌어내고, 비트 3의 *Unsent*가 비트 4의 도이 질문을 끌어내고, 비트 4가 비트 5의 가나 치료 시작과 평행 진행.

2. **EP1 콜드 오프닝과의 시각적 미러링**
   비트 7의 도윤이 노트북 화면 안의 시아를 본다. EP1 콜드의 CCTV 흑백 4:3 → 노트북 컬러 16:9로의 회수. 작품의 시작점과 미드 후 회차가 한 번 더 만난다. *살아 있는 시아의 마지막 영상*.

3. **시그니처 라인의 결정점 배치**
   한도이의 *우리가 지금 하고 있는 거 — 이게 추모예요. 도둑질이에요?* 가 도미노 정점 (S#20)에 배치. 막내가 어른들을 깨우는 voice 시그니처 정점. 마침표 두 개로 *판단인지 질문인지 모호한* 한도이의 voice 정착.

4. **클리프행어 형식 — 결단 + 정보 공개 복합**
   7명의 답이 단톡방에 정렬되는 자막 친화 비트 (S#48). 시청자가 *7인의 자기 결정*을 화면에서 직접 본다. 발화 없이 자막 정렬만으로 결단의 약속 — 자막 친화의 정점.

5. **「뉴」 0건 등장**
   회차 무게를 ECHO 7인 내부로 완전히 가져가는 의식적 결정. 「뉴」의 부재가 *시아 본인의 데이터(미발송 영상)*와 *시아의 빈 의자 위 머리띠*로 대체. 회차 무게 분포 12ep-arc.md 명시 — *EP7은 멤버 내부 회차*.
