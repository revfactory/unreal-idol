대사 0줄 씬 비율 정당화 (53.1%)

자기 검수 기준 25% 이하를 초과하나, EP04는 트리트먼트가 명시한 *회차 정서 곡선 — 외부의 빛과 내부의 어둠의 동속 성장*의 침묵 회차다. 침묵의 자리가 회차의 무게를 직접 받는다:

- 비트 3 김리아 거울 (S#11-S#13): 정면 미노출 + 부산 사투리 *마, 진짜로* 외 발화 없음. 본인이 「뉴」의 몸이 된 자기 인식의 순간 — 대사로 풀면 정서가 풀린다.
- 비트 5 도윤의 윤지윤 서랍 (S#22-S#24): 머리끈 발견의 정밀한 3컷(서랍 여는 손 → 머리끈 클로즈업 → 도윤의 얼굴). 대사로 풀면 시청자의 *기억할까 말까의 경계* 약속이 깨진다.
- 비트 6 어머니 미역국 (S#30, S#35-S#38): 어머니의 그릇 든 채 침묵 7초(S#35) + 싱크대 5초(S#36) + 시아 방 문 앞 머리끈(S#37) + 음소거 텔레비전(S#38). 어머니의 한(恨)은 발화하지 않는 침묵으로만.
- 비트 7 주현 SNS (S#43-S#48): 주현 본인 발화 0건이 트리트먼트 작가적 약속. SNS 본문은 화면 자막으로만 — 자막 친화 + Z세대의 *글이 말이 되는* 시대 톤.

→ EP01 콜드 오프닝(S#1-S#5)이 대사 0줄이었듯, EP04는 회차 전체에 침묵의 자리가 분산되어 정서 곡선의 *상승 회차이지만 의심이 더 큰 회차*를 시각화. 작가적 의도 — 패스.
