## B. 처리 결정 사항 — 마크다운 잔재 → 방송 표준

### B-1. `**굵게**` 처리 원칙

dialogue-writer가 정렬/시각 강조 목적으로 사용한 `**인물명**`, `**컷 N**`, `**비트 N**`, `**최종 컷**` 패턴을 **모두 평문으로** 변환. 한국 미니시리즈 표준에서는 굵게 표시 자체가 불필요 — 작가는 *지문의 평이한 산문체* 안에서 정렬·강조를 수행한다.

**처리 예**:
- `**유하이** — 줄의 맨 앞.` → `유하이 — 줄의 맨 앞.`
- `**컷 1 (1.5초) — 유하이**` → `컷 1 (1.5초) — 유하이`
- `**최종 컷 (2초)**` → `최종 컷 (2초)`
- `**「뉴」**의 얼굴이 완성된다.` → `「뉴」의 얼굴이 완성된다.`
- `**시아 어머니 (이순영, 51)**` → `시아 어머니 (이순영, 51)`

### B-2. `*기울임*` 처리 분류

scene-format SKILL의 *방송 표준 포맷 — 마크다운 금지 사항* 가이드에 따라 다음 3분류:

#### B-2-a. 작가의 결정적 강조 → `작은따옴표`로 보존 (131건)
시청자에게 *돌아보지 않는다*와 같이 *결정적 행동·시그니처 비트*를 작가가 의도적으로 강조한 경우. 한국 방송 작가실에서 *작은따옴표*는 표준적 강조 기호.

**보존 사례 (10개 선별)**:
1. `*돌아보지는 않는다*` → `'돌아보지는 않는다'` (S#1, 시아의 결정적 비트)
2. `*등만 보인다*` → `'등만 보인다'` (S#1, 작품의 첫 시각 시그니처)
3. `*시아의 비공개 표정*` → `'시아의 비공개 표정'` (S#5, 작품 최약속)
4. `*부친의 습관*` → `'부친의 습관'` (S#7, 도윤 voice 시그니처)
5. `*등을 돌린 채*` → `'등을 돌린 채'` (S#8, 회장의 권력 시그니처)
6. `*시아의 사고 현장*` → `'시아의 사고 현장'` (S#9, 도윤의 첫 균열)
7. `*시아의 데뷔 컨셉 보드*` → `'시아의 데뷔 컨셉 보드'` (S#11, 비탄 정점)
8. `*시청자에게만 보이는 비밀*` → `'시청자에게만 보이는 비밀'` (S#46, 비대칭 시그니처)
9. `*학습 데이터에 어머니의 얼굴이 없다*` → `'학습 데이터에 어머니의 얼굴이 없다'` (S#55, 클리프행어 정점)
10. `*불편한 매혹*` → `'불편한 매혹'` (회차 정서 도착점 메타)

#### B-2-b. 자막·시간 코드·시스템 UI → 평문 (26건)
화면에 그대로 나오는 텍스트는 강조 의미가 아닌 *식별 정보*. 평문이 표준.

**처리 사례**:
- `*04:17:32*` → `04:17:32` (시간 코드)
- `*D-58*` → `D-58` (카운트다운 보드)
- `*06:00*`, `*5:47*` → 평문
- `*2027-04-12*`, `*2027-10-23*` → 평문 (학습 데이터 일자)
- `*마지막 업데이트: 03:42:11*` → 평문 (모니터 UI)
- `*백업 진행 중 — 38%*` → 평문 (시스템 알림)
- `*서버실 벽시계: 04:18:09*` → 평문 (시간 코드)
- `*If this is unreal, then so are we.*` → 평문 (영어 가사 자막)
- `*Real or not — we still breathe the same light.*` → 평문 (가사)
- `*We are unreal — and that's the deal.*` → 평문 (가사)

#### B-2-c. 이미 따옴표가 포함된 `*"..."*` → `*` 제거 (15건)
이중 강조를 피하고 따옴표 단독으로.

**처리 사례**:
- `*"5층 연습실. 다 모였습니다."*` → `"5층 연습실. 다 모였습니다."` (S#9 메시지)
- `*"은오야"*` → `"은오야"` (S#12 시아의 글씨)
- `*"라면 끓일까?"*` → `"라면 끓일까?"` (S#41 시그니처 라인 회수)
- `*"23:42:17"*` → `"23:42:17"` (S#57 카운터 텍스트)

### B-3. `---` 구분선 처리 (68건)
한국 미니시리즈 대본에는 *씬 사이 구분선이 존재하지 않는다*. 씬은 `(컷)` 후 한 줄 빈 줄, 그리고 다음 `S#N+1.` 헤더로 자연 시작.

모든 본문 `---` 구분선 제거. 씬 사이 간격은 빈 줄로 정합.

### B-4. `[등장: ...]` → `[등장] ...` 통일 (57건)
대괄호 안 콜론 제거. 모든 씬 헤더의 등장 인물 표기를 표준 형태로 정합. 부재·소리만의 표기(`(가나 부재)`, `(F.)`)는 보존.

## G. continuity-editor에게 인계할 재검수 포인트

1. **S#17 차주영 voice 흔들림**: *"…동의서, 윤지윤 부사장님이 직접 받으셨고."* — *친구 반말 + 부사장 호칭*의 혼재. 의도된 voice 전이인지(친구로서 *그래도 너에게 사실 보고는 격식으로 한다*는 결단인지), 미세 조정이 필요한지 검토.
2. **S#7 박정훈 발화 형식 변경**: dialogue-coach 보강된 `박정훈(E, 무전기 너머)` 한 줄 형식을 `박정훈 (F.)` + `(무전기 너머)` 별도 정서지문 줄로 분리. 대본 리딩 시 호흡이 미세하게 길어지므로 scene-director / continuity-editor 합의 필요.
3. **자막 표기 4건 표준화**: `(자막) ...` → `자막: ...`. 회차 마지막 *"— EP01 끝 —"*은 자막으로 표기 + `(F.O)` 추가. 회차 마감 비트가 *어둠 → 자막 → 페이드 아웃*으로 명시화되었는지 검토.
4. **S#3·S#45 스태프 무전기 발화 분류**: 본 정착에서 *대사로 카운트* (스태프 (F.) 발화 1줄씩). dialogue-coach 진단표는 *무전기/자막만 (PASS)*로 분류 — 메트릭 일관화 필요. 작가 판정 0줄 씬에서는 *스태프 무전기 자막*이지만, 표기상 *대사 블록*이므로 자동 측정과 차이가 발생할 수 있음.
5. **S#13 박정훈 "아니, 두자" 신규 발화 voice 정합**: voice-guide의 박정훈 *지키는 자·짧은 결단·강원도 흔적* 시그니처와 정합. 다만 *"아니. 두자"*의 *반말 종결*이 ECHO 멤버들에게 평소 사용하는 호칭(*애들*+반말)과 일관되는지 확인 권장.
