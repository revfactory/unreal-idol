## 자주 발견된 번역투 패턴 — EP02 사전 경고

### Pattern 1: *시선이 ~에 / 시선이 만난다 / 시선 교환*
- 식별: S#1, S#17, S#21, S#23, S#28, S#32, S#41, S#49, S#55 (총 9건)
- **EP02 작업 시**: *시선이 ~에 닿는다 / ~에 머문다 / 시선 교환 / 두 사람의 시선이 만난다* 전면 회피. *~을 본다 / 눈이 마주친다 / ~에서 눈을 떼지 못한다*로 일관 대체.

### Pattern 2: *응시 / 정면 응시 / 응시한다*
- 식별: S#17, S#48, S#51 (3건)
- **EP02 작업 시**: 「뉴」의 카메라 응시 시그니처(0.4초 → 3.4초 → 11.4초)는 유지. 단, *응시한다·정면 응시로 회전한다* 같은 동사적 활용은 *~을 본다 / 카메라 정면을 본다*로 통일.

### Pattern 3: *그의 / 그녀의 / 그들의* (3인칭 대명사 지문)
- 식별: S#8, S#16, S#23, S#24, S#28, S#43, S#49, S#55, S#56 (9건)
- **EP02 작업 시**: 지문 안 3인칭 대명사 전면 회피. *반드시 이름으로*. 예외: 인물 첫 등장 시 *권력 익명성*을 강조할 때 (S#8 회장의 *카메라가 회장의 얼굴을 잡지 않는다* 정도로 자연화).

### Pattern 4: *~의 결정 / ~의 무게 / 데이터의 호흡* 추상명사 남용
- 식별: S#19, S#29, S#33, S#38 (4건)
- **EP02 작업 시**: 지문에서 추상명사 *~의 ~*의 *호흡·결정·무게·시그니처·결심·정점* 등을 행동·표정으로 바꾸기. 단, 인물 voice의 *결정/책임* 어휘(도윤, 유하이, 윤지윤)는 *대사* 안에서만 보존.

### Pattern 5: 동사 없는 메모형 지문
- 식별: S#27, S#29, S#37, S#45 (4건)
- 예: *시아의 의자 옆에서 한 발 도윤 쪽으로.* / *우측 만짐 종료.* / *정세현의 클러치는 이미 스태프 손.*
- **EP02 작업 시**: 메모형 지문은 *작가의 빠른 스케치 흔적*. 정착 단계에서는 *동사를 채워* 자연화. 단, 시그니처 비트(유하이의 "가자", 박정훈의 "라면 끓일까?")는 그대로 짧음 유지.

### Pattern 6: *사운드 미점등 / 음성은 점등 안 됨* 제작 메모형 지문
- 식별: S#42 (2건)
- **EP02 작업 시**: *점등·미점등·약속 준수* 같은 *조명·연출 부서용 내부 메모*가 지문에 그대로 남는 일 회피. *소리 없음 / 음성 없음 / 자막만*으로 자연 한국어.

### Pattern 7: *처녀 보컬* 시대 부적합 어휘
- 식별: S#4, S#12, S#25 (3건)
- **EP02 이후 전 회차**: *처녀 보컬 / 처녀작 / 처녀비행* 등 *처녀+명사* 시대 어휘 사용 금지. *여성 보컬 / 첫 보컬 모티프*로.

### 검토 권장 부분 (3-5)

1. **S#28 분열의 정점 — 숫자 보정**
   원본 "8명이 16명" → "14명처럼 보인다" 으로 수정. *분열의 정점* 메타포는 유지했으나 가나가 빠진 7명(6인+도윤)+거울 = 14명 산수로 정합. continuity-editor가 *분열의 정점* 정서가 살아 있는지 재확인 권장.

2. **S#33 윤가나 시그니처 라인 정렬**
   "시아 언니 결정에" → "시아 언니 결정이라면" 으로 변경. signature-lines #10 후보와 일치시킴. **continuity-editor가 signature-lines.md를 확정 라인으로 업데이트할지 확인 권장**.

3. **S#37 윤지윤 voice 한자어 보존 vs 자연화 균형**
   "그 결정의 무게를 — 누가 지나요" → "그 결정의 무게는 — 누가 져요" 로 부분 수정. *결정의 무게* 한자어 voice 시그니처는 보존, 조사·동사 활용만 자연화. dialogue-coach에게 *윤지윤 voice의 한자어 비율 30% 유지* 확인 요청.

4. **S#46 도윤 voice — *결정*의 무게 보존**
   codex가 *결심*으로 약화 제안했으나 도윤 voice의 *결정의 무게 시그니처*(signature-lines #3 *도윤의 침묵*)를 보존. continuity-editor가 EP03~EP12 전반에서 도윤이 *결정*과 *결심* 두 어휘를 어떻게 분리·사용하는지 트래킹 권장.

5. **S#56 어머니의 침묵 — *그녀의 손* → *이순영의 손***
   회차 클리프행어의 시그니처 한·恨 비트. *그녀의*보다 *이순영의*가 어머니의 *고유성·정서적 닻*을 더 강하게 함. signature-lines #4 "어머니의 침묵"과 정렬. EP06 *"우리 딸 데이터 사용에 동의한 적 없어요"* 빌드업의 시작점이므로 이름 강조가 정확.
