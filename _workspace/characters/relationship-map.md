# 관계도 — 〈언리얼 아이돌〉

> 시아 중심부 + 「뉴」 위성 + 회사 내부 권력 구도 + 라이벌 회사 + 외부 매개자. 5층 관계망.

---

## 1. 작품의 척추 — 시아 중심부 (모든 관계의 원점)

```
                          [시아 어머니 (이순영)]
                                    │
                                    │ 모녀
                                    │
                           ┌────────┼────────┐
                           │        │        │
                       [시아 아버지] │   [시아 동생]
                       (이형식)     │   (이주현)
                                    │
                                    │ 어머니 가족
                                    │
                              ╔════════╗
                              ║  시아  ║ ← 사망 (작품 시작 직전)
                              ║(이주아)║
                              ╚════════╝
                              ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃
                              ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃
                              ┃ ┃ ┃ ┃ ┃ ┃ ┃ ┃ (각 줄 = 7인 + 도윤과의 미해결)
        ┌──────┬──────┬──────┼──┼─┼─┼─┼──────┬──────┐
        │      │      │      │  │ │ │ │      │      │
   [유하이] [민서린] [차로아] [박은오] [정세현] [윤가나] [한도이] ← ECHO 7인
        │                                                  │
        └────────── 9년 자란 한 그룹 ──────────────────────┘
                          │
                          │ 직속 프로듀서
                          ↓
                    [한도윤 (PD)]
                          │
                          │ 외부 친구
                          ↓
                    [한유진] (IRIS 메인 보컬)
                    ── 시아의 사고 직전 마지막 통화 상대
```

**선의 의미**:
- 두꺼운 선(┃): 작품 전체 갈등 핵심 — 시아 ↔ ECHO 7인 ↔ 도윤
- 보통 선(│): 회차 단위 갈등 영향 — 시아 ↔ 가족, 시아 ↔ 한유진
- 점선(없음 표시): 잠재 관계 — 시아 ↔ 「뉴」 (아래 별도)

## 2. AI 위성 — 「뉴」의 관계망

```

                            (AI 엔지니어)
                                │
                                │ 코드 작성자
                                ↓
                            ╔════════╗
                            ║  「뉴」 ║ ← AI 페르소나
                            ║  (NEU) ║   (시아의 데이터로 만들어짐)
                            ╚════════╝
                                ▲
                                │ 신체 캡처
                                │
                            [김리아]
                          (모션 캡처 댄서)
                              │
                              │ NDA 비공개
                              ↓
                          [박정훈 매니저]
                          (김리아의 유일한 회사 내 인지자)

                            「뉴」의 무대 위 관계 (학습된 행동)
                            ──── ECHO 7인에게 각각 다른 패턴 ────
                                    │
                                    ↓
        ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐
     유하이  민서린  차로아  박은오  정세현  윤가나  한도이
       (언니) (손잡기) (어깨) (응시) (회피)  (호흡)  (본명)

                            「뉴」가 도윤만을 향한 행동
                            ──── 카메라 응시 + "도와줘" 입 모양 ────
                                    │
                                    ↓
                                [한도윤]
```

## 3. 회사 내부 권력 구도 — 올텀 엔터테인먼트

```
                            [송재완 회장]
                          (시스템 안타고니스트)
                                │
                                │ 결재 권한
                                │
                    ┌───────────┼───────────┐
                    │           │           │
              [윤지윤 부사장]    │    [기타 임원진]
            (시아 사수·키운자) │      (작품 거의 등장 X)
              │                 │
              │ 시아의 의료      │ 메인 PD
              │ 트레이닝 통제    │
              │                 │
              ↓                 ↓
        시아 부모 ──── 신뢰    [한도윤 PD]
        (윤지윤을 은인으로 인식) │
        ──────────────────────  │ 직속 부하 + 친구
                                │
                          [차주영 엔지니어]
                                │
                                │ 코드 작성
                                ↓
                              「뉴」
                                │
                                │ ECHO 데뷔조 관리
                                ↓
                          [박정훈 매니저]
                                │
                                │ 멤버 케어
                                ↓
                          ECHO 7인
```

**핵심 권력 흐름**:
- 회장 → 부사장(지윤) → PD(도윤) + 매니저(정훈) → ECHO 7인 + 시아 가족
- 차주영(엔지니어)은 *기술 라인* 별도 — 도윤과 친구 관계로 회사 위계 외 동맹

## 9. 회차별 *처음 만나는 두 인물* 배치 (인물 동맹의 회차 비트)

| 회차 | 첫 만남 / 새 동맹 | 의미 |
|------|----------------|------|
| EP1 | (이미 형성된 관계) | ECHO 7인 + 도윤 + 시아 가족 |
| EP2 | 「뉴」 ↔ ECHO 7인 (학습되지 않은 인사) | AI와 인간의 첫 균열 |
| EP3 | (이미 형성된 외부 인물 첫 노출) | 일라이자·강하늘·진우의 그림자 |
| EP5 | 일라이자 ↔ ECHO 매니저 / 강하늘 ↔ 시아 동생 | 외부 라인 시작 |
| EP6 | 일라이자 ↔ 시아 어머니 / 「뉴」 ↔ 도윤("도와줘") | 진실 폭로의 매개 시작 |
| EP7 | 서린 ↔ 한유진 / 유하이 ↔ 가나 (양치 발견) | 진실 추적의 친구 동맹 / 멤버 내 보호 |
| EP8 | 도윤 ↔ 차주영 (동생 백스토리) / 도윤 ↔ 진우 (과거 폭로) | 동맹의 정서적 확장 / 두 남성의 백스토리 |
| EP9 | 한유진 ↔ 서린 / 도이 ↔ 주현 | 친구 동맹 확정 / 어린 두 인물의 위로 |
| EP10 | 강하늘 ↔ 서린 / 김리아 → 세현 (익명 편지) | 외부 라인의 동맹 통합 |
| EP11 | 모든 인물의 *기자회견* 합류 | 동맹의 정점 |
| EP12 | (도윤 ↔ 서린의 동료적 정착) | 작품 마침 |

## 10. 작품 전체의 관계망 — 한 페이지 요약

```
                                    [회장]
                                  (시스템 안)
                                      ▲
                                      │
                                  [윤지윤]
                                  (내부 안)
                                      ▲ │
                                      │ ↓
                       ┌──── 시아 가족 ────┐
                       │       (어머니·       │
                       │     아버지·동생)     │
                       │          │           │
                       │          ▼           │
                       │     ╔═══════╗        │
                       │     ║ 시아  ║ ◀──── [한유진] (외부 친구)
                       │     ╚═══════╝        │
                       │          │           │
                       │      ┌───┴───┐       │ ◀── [강하늘] (팬덤)
                       │      ▼       ▼       │
                       │   ECHO 7인 ◀──┐     │ ◀── [일라이자] (다큐)
                       │      │        │     │
                       │      ▼        │     │
                       │  [도윤 PD] ────┘     │
                       │      │               │
                       │      ▼               │
                       │  [차주영] ─→ 「뉴」 │
                       │      │       ▲      │
                       │      ▼       │      │
                       │  [박정훈] ←─[김리아]│
                       │  (매니저)            │
                       └──────────────────────┘
                                ▲
                                │ (10년 전 동료, 8회 폭로)
                                │
                            [장진우]
                          (외부 안)
```

**3중 안타고니스트의 위치**: 회장(위)·지윤(옆)·진우(밖). ECHO와 시아 가족이 세 안타고니스트에 둘러싸인 형태.

---

*작가 메모: 관계도는 회차마다 *변화*. 1회의 관계도는 *시아 중심부 + ECHO 7인 + 도윤*까지만 시청자에게 명확. 외부 매개자 3인(강하늘·일라이자·한유진)은 *3-5회에 점진적 등장*. 11회 기자회견에서 *모든 관계망이 한 자리에 모임*. 12회 마지막 무대 객석에서 *모든 인물이 시아의 자작곡을 함께 들음*. 군상극의 시각적 정점.*
