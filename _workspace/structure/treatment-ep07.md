# EP7 트리트먼트 — 「발신함의 침묵」

## 한 줄 요약
> 미발송 메시지·시아의 손편지·도이의 결정적 질문·가나의 치료 시작 — 발견의 누적이 멤버 각자의 사적 진실을 무너뜨린다.

## 회차의 역할
- **미드포인트 직후의 *사적 진실의 도미노* 회차**
- 발견들이 *나열*이 아닌 *연쇄*가 되도록 구조화 — 한 발견이 다음 발견을 *호명*
- ECHO 내부 회차 — 외부 인물 비중 의도적 축소

## 회차 정서 곡선
- **시작**: 어둠 잔류 — EP6 미드포인트의 *"도와줘"* 후유증
- **중반**: 도미노 — 발견이 연쇄적으로 발화
- **끝**: 균열 안의 결속 — 7인이 각자의 진실을 들고 서로를 본다

## A 플롯 / B 플롯
- **A**: 유하이의 미발송 메시지 발견 → 단톡방 공유 → 은오의 손편지 공개 → 도이의 도윤 질문
- **B**: 가나의 치료 시작 + 서린의 어머니 췌장암 발견 (개인 라인)

## 회차 정서적 도착점
시청자가 *"이 작품의 진짜 미스터리는 시아의 사고 그 자체가 아니라, 7인이 시아를 어떻게 몰랐는가의 미스터리다"*를 인지. 회차의 무게가 *외부*에서 *내부*로 완전히 전환.

2. 비트 4의 도이·도윤 씬은 *2샷 + 침묵 + 클로즈업 교차*. 도이의 18세 얼굴이 도윤의 31세 얼굴을 *압도*. 카메라 워크로 *어른의 위치가 바뀜*을 보여줌
3. 비트 7의 도윤이 미발송 영상을 보는 씬은 *노트북 화면 + 도윤의 얼굴*의 정확한 미러링. 시아의 14인치 노트북 화면 안의 *살아 있는 시아*가 도윤의 화면에 그대로 비춰짐 — *EP1 콜드 오프닝과의 시각적 연결*
4. 비트 9의 단톡방 합의는 *7개의 답이 차례로 등장하는 애니메이션*. 각 멤버의 voice가 텍스트의 *글꼴/타이밍 차이*로 구별 가능하게
