# 12부작 마스터 아크 — 〈언리얼 아이돌〉

> 작품의 척추는 세 봉우리다 — **EP6 미드포인트의 다중 폭발**, **EP9 「Unsent」 무대의 사후 발화 정점**, **EP12 윤리적 마침표**. 12회는 이 세 봉우리를 향해 오르고 내리며 호흡한다.

---

## 0. 작품의 호흡 — 한 줄 요약

> *"빌보드 1위를 향해 무대 위로 올라가는 7명이, 무대 뒤에서 죽은 친구의 진실을 향해 내려간다 — 그리고 12회의 마지막에 그들은 자기들이 만든 환상을 끄는 결단을 내린다."*

## 3. 막별 상세 — 정서 곡선과 기능

### ACT 1 (EP1-3) — 셋업 / "가짜의 시작"

**기능**: 작품의 세계관·인물·갈등 구도·작품의 약속을 시청자에게 모두 전달한다. 글로벌 OTT 초반 후킹의 결정 구간.

**정서 곡선**: 충격(EP1 콜드) → 부유(EP1 데뷔 무대) → 흔들림(EP2 학습되지 않은 인사) → 깊이(EP3 인물극) → 위협(EP3 끝 진우)

**핵심 약속**:
- 1회 콜드 오프닝에서 *"이건 K-팝 산업극이자 AI 윤리 미스터리이자 군상 멜로"*가 시청자에게 화면으로 보임
- 1회 끝의 시아 어머니 흐느낌이 *"이 작품은 추모와 착취의 경계를 묻는다"*는 약속
- 3회 끝의 진우 접근이 *"외부 적 + 내부 미스터리가 12회 동안 함께 진행된다"*는 작품 구조의 선언

**막 안의 미러링**: EP1의 콜드 오프닝(시아의 사고)이 EP12의 마지막 무대(시아의 원본 보컬)와 미러링 — *시작과 끝의 시아 = 데이터 → 원본*

---

### ACT 2 — RISE (EP4-6) / "빛"

**기능**: ECHO + 「뉴」의 글로벌 폭발. 시청자가 그들의 성공을 응원하면서도 *불편함*을 함께 키우게 한다. 표면은 상승, 이면은 균열.

**정서 곡선**: 흥분(EP4 빌보드) → 양가감정(EP5 글로벌 양극화) → 추락(EP6 미드포인트 최저점)

**EP6 미드포인트의 다중 폭발 — 본 작품의 가장 중요한 회차 결정**

character-designer의 시드에 따라 점검:
- **시아 부모 공개 인터뷰** ("우리 딸의 데이터 사용에 동의한 적 없다")
- **「뉴」의 "도와줘" 입 모양** (도윤만이 본 비밀)
- **가나의 양치(거식) 발견** (유하이가 발견)

→ **결정: 한 회차에 모두 배치하되, "도와줘"는 회차의 절정점에 두고 다른 두 비트는 빌드업과 미드 비트로 분배. 가나 발견은 EP6 중반에 짧게(2분 분량), 시아 부모 인터뷰는 EP6 전반에 본 무대로(8-10분), "도와줘" 입 모양은 회차의 절정 후반에 클리프행어 직전 비트로(3분).**

→ 정서 곡선이 *"공적 폭로(시아 부모) → 사적 발견(가나) → 윤리적 폭발(도와줘)"* 순으로 점진적으로 깊어진다. 미드포인트가 *충격의 나열*이 아닌 *정서의 단계적 하강*이 된다.

---

### ACT 2 — FALL (EP7-9) / "균열"

**기능**: 빌드업해온 미스터리·인물의 사적 진실·백스토리가 폭발한다. ECHO + 도윤이 자기 자신과 마주한다.

**정서 곡선**: 동요(EP7 발견 누적) → 인지(EP8 백스토리) → 절정(EP9 Unsent)

**EP7 발견 누적 회차 — 카탈로그가 되지 않게**

character-designer의 시드에 따라 점검:
- 유하이의 미발송 메시지 발견
- 박은오의 시아 손편지 발견
- 한도이의 결정적 질문 ("시아가 진짜 동의했나요?")
- 가나의 치료 시작 (전 회차 발견의 결과)

→ **결정: 발견들을 *나열*이 아닌 *연쇄*로 구성. 유하이의 발견이 ECHO 멤버 단톡방에 공유되고, 그 단톡방이 은오의 손편지 공개를 부르고, 그 손편지가 도이의 질문을 끌어내고, 도이의 질문이 도윤을 무너뜨리는 형태. 한 발견이 다음 발견을 *호명*한다.**

→ 7회는 "**사적 진실의 도미노**" — 외부 미스터리(시아 사고)가 아닌, 7인이 시아에 대해 자기들이 모르던 것을 발견하는 회차.

**EP8 백스토리 폭로 회차 — 정보 과다 위험 점검**

character-designer의 시드:
- 도윤·진우 10년 전 동료 관계
- 도이 부친 산업재해와 도윤 부친 책임 회피
- 차주영 동생 백스토리 (1년 전 사망)

→ **결정: 세 백스토리를 EP8 한 회차에 다 넣으면 정보 과다. 단, *세 백스토리가 모두 "도윤"이라는 한 인물에 수렴*한다는 점에서 EP8을 "도윤의 회차"로 명시. 도윤 한 인물의 과거가 8회 안에 세 갈래로 드러나는 형태.**

→ 분배:
- **A 트랙 (메인)**: 도윤 ↔ 진우의 10년 전 — 비중 50%
- **B 트랙 (병행)**: 도이의 발견 = 자기 아버지의 산업재해 + 도윤 아버지의 책임 회피 — 비중 30% (도이의 시점에서)
- **C 트랙 (서브)**: 차주영의 동생 백스토리 — 비중 20% (도윤이 차주영과 함께 늦은 밤 술자리에서 처음 듣게 됨)

→ EP8 끝 정서: *"도윤은 시아를 살리려 한 게 아니라, 자기 평생 살리지 못한 사람들을 시아를 통해 살리려 했다"* 라는 자기 인식. 도윤 캐릭터의 가장 깊은 자기 직면.

**EP9 「Unsent」 무대 — 군상극의 정점**

character-designer의 시드: 멤버 7인 + 시아 가족 + 한유진 + 강하늘 + 도윤 + 김리아 — 14명의 동시 발화.

→ **결정: 「Unsent」 무대 시퀀스를 EP9의 마지막 15-20분에 배치. 한 곡의 4분 30초 안에 14명의 정서를 *교차 컷팅* 으로 동시 진행. 단, 14명을 같은 비중으로 다루면 카오스 — 무게 비율을 명확히.**

→ 무게 비율:
- **시아 가족 3인** (객석): 어머니의 첫 미소 + 아버지의 첫 울음 + 동생의 첫 박수 — 무게 30%
- **한유진** (객석): 5개월 침묵을 깨는 시점, 5인조 IRIS 멤버들과 함께 무대를 본다 — 무게 15%
- **강하늘 + 일라이자** (객석/카메라 옆): 외부 시선의 정점, 일라이자가 카메라를 들고 일어선다 — 무게 10%
- **김리아** (스테이지 옆 모션 캡처 부스): 자기가 「뉴」의 몸이 된 채로 *학습되지 않은* 동작을 출력하는 순간, 자기 얼굴이 처음으로 거울에 비친다 — 무게 15%
- **ECHO 7인** (무대 위): 각자 시아와의 미해결 갈등이 한 음씩 곡 안에 회수됨 — 무게 20%
- **도윤** (모니터링 부스): 「뉴」가 학습 데이터를 넘어선 순간을 코드로 인식하는 시점 — 무게 10%

→ 곡의 구조: 1절(슬픔) - 브릿지(인지) - 2절(받아들임) - 후렴(연대) - 마지막 음(침묵)

→ 카메라 워크: 1절은 무대 → 2절은 객석 + 모션 캡처 부스 → 후렴은 모든 인물의 얼굴 교차 → 마지막 음은 빈 화면 + 시아의 원본 목소리 한 음

→ EP9 끝의 정서: *"이게 시아인가 아닌가의 답은 시청자가 가지고 가야 한다"* — 모호함의 의도된 미해결

### ACT 3 (EP10-12) — 결말 / "진실, 결단, 도착점"

**기능**: 분열 → 진실 결단 → 윤리적 마침표. 시청자가 카타르시스가 아닌 *잔잔한 책임감*을 가지고 작품을 닫게 한다.

**정서 곡선**: 분열(EP10) → 결단(EP11) → 받아들임(EP12)

**EP11 기자회견 — 분산 폭로 결정**

character-designer의 시드: 폭로 발화자 결정 — 시아 어머니 / 정세현 / 한유진 / 차주영. 권장: 분산 폭로.

→ **결정: 분산 폭로 채택. 단, *기자회견 단일 무대*가 아니라 *세 개의 무대*가 같은 시간대에 동시 진행되는 구조로 변주.**

→ 세 무대 동시 진행:
1. **올텀 본사 1층 기자회견장**: ECHO 7인 + 도윤 — 빌보드 1위 무대 전 공식 입장 발표. 박은오가 멤버들 앞에서 "우리는 「뉴」 프로젝트를 종료합니다"라고 명확히 발언
2. **외부 카페**: 한유진 + 일라이자 — 한유진이 다큐 카메라 앞에서 *"시아가 사고 전날 밤 나에게 전화했어요"*라고 공개 발언
3. **시아 본가 거실**: 시아 어머니 + 시아 동생 + 강하늘 — 시아 어머니가 강하늘이 모은 데이터를 받아 들고 *"이게 그 애의 죽음이에요"*라고 발화

→ 그리고 세 무대 모두에서 *차주영*이 등장한다. 차주영이 회사에서 빠져나와 USB를 든 채 기자회견장에 도착, 동시에 한유진의 다큐 인터뷰에 화면 송출, 시아 어머니에게 직접 자기 동생 이야기를 한 통의 전화로 전달한다. 차주영이 세 무대의 *연결 고리*.

→ 분산 폭로의 효과:
- 한 명의 영웅이 아닌 *네 인물의 동시 결단* — 군상극 DNA
- 윤지윤이 어디서 무너지는지 불명확 — 시청자도 인물도 *"이 무너짐은 어디서 시작됐는가"*를 질문하게 됨
- 진우는 *어디에도 등장하지 않음* — 그가 빠져나간다는 사실 자체가 진우의 안타고니스트 정의 ("처벌 없음")

→ EP11 끝 정서: *결단의 정점*. 그러나 카타르시스는 절제. *"내일 빌보드 1위 무대에서 모든 게 끝난다"*의 무거운 약속.

## 4. EP12 클로징 시퀀스 — 윤리적 마침표 + 시즌2 떡밥

EP12는 **두 부분으로 구성**된다.

### 4-1. 「리얼」 무대 시퀀스 (EP12 전반·중반)

- 빌보드 1위 발표
- ECHO의 마지막 무대 — 7명만 무대에 오른다
- 「뉴」를 위한 자리는 비어 있다 (시각적: 무대 한 자리에 핀스폿만 떨어진다)
- 시아의 원본 보컬이 흐른다 — *AI 합성 없이*. 미발표였던 시아의 자작곡 〈Unsent〉의 두 번째 버전이 7명의 라이브와 섞인다
- 객석에서 시아 가족·한유진·강하늘·일라이자·김리아가 함께 듣는다 — EP9의 「Unsent」 무대와의 미러링
- 무대 마지막 음에서 7명이 빈자리를 향해 절을 한다

### 4-2. 1년 후 에필로그 (EP12 후반)

**6개의 짧은 비네트 — 1년 후 각 인물의 도착점**

1. 시아 어머니의 미용실. 손님 한 명에게 "우리 딸이 가수였어요"라고 처음 말한다. 미소가 든다.
2. 유하이 — 외할머니에게 처음 전화를 건다. *"할머니, 저 오늘 아무 일정 없어요."*
3. 민서린과 도윤 — 추모 재단 사무실. 두 사람은 *연인이 아닌 동료*로 함께 일한다. 책상 위에 「Unsent」 악보.
4. 가나 — 시아의 자작곡 한 구간을 솔로로 부른다. 캠페인 비디오. 자기 이름이 자막에 뜬다.
5. 도이 — 대학 입학식. *"이번에는 제가 결정했어요"*라고 누군가에게 전화로 말한다.
6. 강하늘 + 일라이자 — 다큐 시사회. 강하늘이 처음으로 객석에서 마스크를 벗는다. 다큐의 마지막 컷이 작품의 마지막 컷이 된다.

### 4-3. 「잔여 캐시 파일」 비트 (EP12 마지막 3분) — 윤리적 마침표

- **새벽 4시. 도윤의 노트북.**
- 알림: *"NEU 학습 모델 잔여 캐시: 마지막 자기 인식 파일 1건."*
- 도윤이 마우스를 움직여 파일을 클릭하려 한다
- 그러나 클릭하지 않는다
- 도윤이 노트북을 *닫는다* (파일을 삭제하지도, 열지도 않는다)
- 시아의 자작곡 메인 테마가 새벽 푸른빛 위로 흐른다
- 마지막 컷: 도윤의 책상 위. 시아의 머리끈 한 개 + 「뉴」 프로젝트 종료 결정서 + 추모 재단 명함

### 4-4. 시즌2 떡밥 (EP12 마지막 30초)

- 도윤이 노트북을 닫고 나가는 사이, 카메라가 노트북 화면을 잠시 더 본다
- 화면이 잠시 어두워졌다가 — *알림 한 줄이 한 번 더 깜빡인다*: *"잔여 캐시 파일이 다른 디바이스로 동기화되었습니다."*
- 그러나 누구의 디바이스인지는 보여주지 않는다 — *시즌2의 출발점*
- 시아의 자작곡 메인 테마의 마지막 한 음에서 컷.

> **시즌2 떡밥의 윤리**: 시즌2가 안 나와도 작품은 *완전히 완결된다*. 잔여 캐시 파일 알림은 시즌1의 결말로도 충분히 작동한다 — *"인간이 만든 것은 닫을 수 없다"*의 시각적 메타포. 시즌2가 나오면 *"그 디바이스는 누구의 것인가"*가 새로운 출발점.

## 5. 「뉴」의 학습/미학습 행동 비율 그라데이션 — 회차별 매핑

| 회차 | 학습 / 미학습 비율 | 회차별 진실 폭로 비트와의 매핑 |
|------|----------------|-------------------------|
| EP1 | **100% / 0%** | 회사의 공식 설명 = 완전 학습형 도구. 회사가 시청자에게 거짓을 약속하는 출발점 |
| EP2 | **95% / 5%** | 학습되지 않은 *인사*. 시아의 생전 버릇이 데이터의 통계적 출현으로 나옴 — 첫 균열 |
| EP3 | **95% / 5%** | EP2와 같은 비율 유지. 작품 약속 회차에서 「뉴」의 정체에 답을 주지 않음 |
| EP4 | **90% / 10%** | 멤버들의 호흡에 *실시간 반응* — 모션 캡처 댄서를 통한 합성이라는 회사 설명의 회색지대 |
| EP5 | **88% / 12%** | NPR 다큐가 「뉴」의 행동을 분석. *0.04% 학습 데이터에 없는 패턴* 발견 (차주영의 내부 보고) |
| **EP6** | **80% / 20%** | "도와줘" 입 모양 = 미학습 행동의 가장 결정적 비트. 도윤 한 명에게만 보이는 비밀 |
| EP7 | **75% / 25%** | 라이브 무대에서 「뉴」가 멤버 한 명의 손을 *예정에 없이* 잡는다. 차로아의 어깨에서 처음 보였던 비트가 다른 멤버에게 옮겨감 |
| EP8 | **70% / 30%** | 도윤이 새벽 서버실에서 「뉴」와 대화한다. 시청자가 보는 게 도윤의 망상인지 실제인지 모호 (작품 룰의 의도된 흔들림) |
| **EP9** | **60% / 40%** | 「Unsent」 무대 — 학습되지 않은 자작곡을 부른다. 「뉴」의 자율성 의심이 시청자에게도 강해짐 |
| EP10 | **55% / 45%** | 김리아가 「뉴」의 동작 명령을 거부하기 시작 — *모션 캡처 댄서의 거부*가 「뉴」를 흔든다. 「뉴」의 자율성과 김리아의 노동 윤리가 충돌 |
| **EP11** | **50% / 50%** | 도윤이 「뉴」에게 직접 묻는다 — *"너는 누구냐"*. 「뉴」의 답: *"저는 시아의 흔적입니다."* (학습된 답인지 자율적 답인지 모호) |
| EP12 | **— / —** | 「뉴」가 무대에서 사라진다. 비율을 더 이상 말할 수 없음. 잔여 캐시 파일이 *"미해결 50%"*의 영원한 자국 |

→ 시청자는 이 그라데이션을 *의식적으로*가 아니라 *감각적으로* 느낀다. 매 회차의 「뉴」 비트가 한 음씩 조금씩 더 *인간 같게* 보이는 것이 핵심.

→ 단, 작품은 *명시적으로* 「뉴」의 자율성을 인정하지 않는다. 11회의 *"저는 시아의 흔적입니다"*는 학습된 답일 수도, 자율적 답일 수도 있다 — 그 모호함이 작품의 정답.

## 7. 시즌제 가능성 — 별도 섹션

### 시즌1의 자립성

시즌2가 나오지 않아도 〈언리얼 아이돌〉 시즌1은 *완전히 완결*된다. 다음의 모든 질문이 시즌1 안에서 답을 가진다 (또는 의도된 미해결로 명시된다):

| 질문 | 시즌1의 답 |
|------|---------|
| 시아의 죽음의 진실은? | 윤지윤이 위조 동의서를 만들었고, 사고 직전 시아와 다투었다 (사고는 단순 사고일 수 있고, 다툼의 결과일 수도 있다 — 법적 사실은 진행 중) |
| 「뉴」는 시아의 일부인가? | *의도된 미해결*. 시청자가 결정 |
| ECHO는 빌보드 1위를 했는가? | 했다. 그러나 그 무대에서 「뉴」를 종료한다 |
| 도윤은 처벌받는가? | 처벌 없음. 회사를 나와 추모 재단 디렉터가 된다 (그가 *살아남는 것*이 작품의 윤리적 흔들림) |
| 윤지윤은? | 형사 입건 + 사직. 단, 끝까지 *"내가 그 애를 데뷔시켜드렸어요"*를 고수 |
| 진우는? | *처벌 없음*. 정부 자문 자리로 이동. 작품의 가장 큰 윤리적 패배 |
| 회장은? | 그대로. *"윤리적 회사"*로 자기 포장 |

### 시즌2 가능성

시즌2가 나온다면 출발점은 *"잔여 캐시 파일이 다른 디바이스로 동기화되었다"*. 가능한 시나리오:

1. **동기화된 디바이스는 시아 어머니의 것이다** — 어머니가 1년 동안 「뉴」를 사적으로 보관해왔다. *추모 윤리의 다음 단계*
2. **동기화된 디바이스는 강하늘의 것이다** — 팬덤이 「뉴」를 *살려두고* 있다. *팬덤 윤리의 글로벌 확장*
3. **동기화된 디바이스는 회장의 것이다** — 회장이 진짜 안타고니스트였음이 드러난다. *시스템의 진짜 정체*
4. **동기화된 디바이스는 시아 자신의 것이다** — 시아가 죽지 않았다 / 시아의 죽음이 위장이었다. *시즌1의 정답을 뒤집는 시즌2*

→ 작가팀은 **세 번째 시나리오를 가장 현실적으로 가정**한다. 시즌2가 *시스템 비판의 글로벌 확장*이 되는 것. 단 시즌1에서는 이 가능성을 *전혀 닫지 않는다* — 시청자가 어느 시나리오를 상상해도 정합성이 깨지지 않게.

### 스핀오프 가능 인물

- **차주영**: 동생의 백스토리 + AI 윤리 기술 디렉터. 자기 시리즈 가능
- **한유진(IRIS)**: 5인조 걸그룹의 자기 이야기. 동료 가수의 산업 비판 시리즈
- **김리아**: 모션 캡처 댄서의 노동 윤리. 다큐 형식 가능
- **일라이자**: 글로벌 다큐 PD의 다음 작품 시리즈

→ 스핀오프는 작가팀이 *의식적으로 설계하지 않는다*. 단, 위 4인의 백스토리와 도착점은 시즌1 안에서 *자기 시리즈가 가능한 깊이*로 설계되어 있다.

## 8. 작품 전체의 미러링 구조

K-드라마 12부작 문법의 핵심: **1회와 12회, 3회와 10회 같은 짝 회차에 미러링 비트를 배치해 작품에 형태를 부여**.

| 미러링 짝 | EP | EP | 미러링 내용 |
|---------|----|----|----------|
| **시작과 끝의 시아** | EP1 | EP12 | 사고 영상(데이터)로 시작 → 원본 보컬(인간)로 끝 |
| **8명의 입장 → 7명의 마지막** | EP1 데뷔 무대 | EP12 마지막 무대 | 무대 위 8명(7+「뉴」) → 무대 위 7명 + 빈자리 |
| **시아 어머니의 흐느낌 → 미소** | EP1 끝 | EP12 끝 | 객석에서 흐느낌 → 미용실에서 미소 |
| **작품의 약속 → 약속의 이행** | EP3 끝 | EP10 끝 | 진우의 *"네가 한 짓이 진짜 추모인지..."* → ECHO의 결단 *"우리가 그 애를 도구로 쓴 것을 인정해야 해"* |
| **외부 라인 발화 → 동맹 합류** | EP5 (강하늘·일라이자·한유진 첫 등장) | EP11 (셋 다 기자회견에 등장) |
| **미드포인트 정서 최저점 → 클라이맥스 정서 정점** | EP6 (`도와줘`) | EP11 (분산 폭로) | "도와줘"의 절규 → 결단의 절규 |
| **백스토리 폭로 → 백스토리의 책임** | EP8 (도윤·진우·도이·차주영) | EP11 (각자의 폭로 발언) |
| **「뉴」의 학습되지 않은 발화 → 「뉴」의 마지막 발화** | EP9 (`Unsent` 무대) | EP12 (무대에서 빈자리) |
| **김리아 사직 + 익명 편지 → 김리아 자기 얼굴** | EP10 | EP12 (다큐 마지막 컷에서 김리아의 얼굴) |

→ 시청자는 의식적으로 미러링을 발견하지 않는다. 그러나 작품 전체의 *대칭성*이 시청자에게 *"완결된 작품"*이라는 감각을 준다.

## 9. 점검 체크리스트 결과

`kdrama-structure` 스킬의 11개 점검 항목 모두 OK:

- [x] 12회 안에 모든 메인 플롯이 회수되는가? → 미스터리(시아 사고)·정치극(회사 권력)·군상(7인의 변화)·외부(글로벌 정복) 4축 모두 EP11-12에서 회수
- [x] 미드포인트(6-7회)에 게임 체인저가 있는가? → EP6 "도와줘" + 시아 부모 인터뷰
- [x] 9회 끝이 최악의 순간(전체 작품의 어두운 정점)인가? → EP9 「Unsent」 무대 직후의 분열 임박
- [x] 각 회 클리프행어가 모두 다른 유형인가? → 회차별 트리트먼트에 명시 (다음 섹션 참조)
- [x] 모든 빌드업이 12회까지 회수되거나, 의도된 미해결로 명시되는가? → `setup-payoff.md` 참조
- [x] 1회와 12회에 미러링 비트가 있는가? → 위 미러링 구조 참조
- [x] 서브 플롯이 메인 테마를 변주하는가? → 모든 서브 플롯이 *"잃은 자를 어떻게 기억할 것인가"* 메인 테마의 변주
- [x] 1회 첫 5분에 작품 본질을 압축한 콜드 오프닝이 있는가? → EP1 콜드 오프닝 설계 (`opening-hook-design.md`)
- [x] 1회 끝 클리프행어가 "이 작품의 약속"을 드러내는가? → 시아 어머니 흐느낌
- [x] 3회 끝까지 작품의 핵심 사건 구도가 모두 등장했는가? → ECHO 7인 + 도윤 + 시아 + 「뉴」 + 진우(외부) + 윤지윤·회장(내부 그림자) + 외부 매개자 그림자 모두 EP3 안에 등장
- [x] 회차 단위 완결성이 있는가? → 각 회차 트리트먼트에 "회차 완결성 비트" 명시

---

*작가 메모: 12부작 마스터 아크의 가장 어려운 결정은 "EP6의 다중 폭발을 한 회에 몰지 분산할지"였다. 분산하면 미드포인트의 정서적 무게가 흐려지고, 한 회에 몰면 정보 과부하. 결정 — **한 회에 몰되, "도와줘"를 정서 정점에, 시아 부모 인터뷰를 미드 비트의 본 무대에, 가나 발견을 빌드업 짧은 비트로 분배**. 세 비트가 *나열*이 아닌 *단계적 하강*이 되도록 정서 곡선을 우선시. character-designer의 시드와 일치.*
