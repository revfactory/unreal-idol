# Continuity Check — 검수 체크리스트

12부작 드라마 대본을 검수하는 절차와 체크리스트. continuity-editor는 단일 회차 검수와 회차 간 비교 검수를 모두 수행한다.

## 검수 5축

| 축 | 검수 대상 | 자주 발생하는 버그 |
|----|---------|---------------|
| 인물 일관성 | voice, 나이, 관계, 신념, 외형 | 말투 드리프트, 관계 호칭 변화, 인물 정보 미세 변경 |
| 시간선·공간 | 사건 순서, 이동 시간, 장소 묘사 | 이동 시간 불일치, 같은 장소가 다르게 묘사 |
| 빌드업-페이오프 | setup-payoff.md 추적 | 회수 안 되는 빌드업, 정당화 없는 페이오프 |
| 세계관 룰 | bible/world.md, tone-theme.md | 작품 룰 위반, 톤 일탈 |
| 정보 흐름 | 시청자가 알아야 할 정보의 노출 타이밍 | 정보 누설 (너무 빨리 노출), 정보 누락 |

## 검수 단계

### 단계 1: 단일 회차 검수
회차 대본 완성 직후 즉시 실행. 회차 내부의 일관성만 본다.

체크 항목:
- [ ] 씬 헤더의 시간 흐름이 회차 내에서 일관되는가? (새벽 → 아침 → 낮 순서를 어기지 않는가)
- [ ] 같은 인물의 말투가 회차 안에서 일관되는가?
- [ ] 같은 장소가 회차 안에서 일관되게 묘사되는가?
- [ ] 인물의 동선이 물리적으로 가능한가? (A 씬 끝 → B 씬 시작 사이의 이동 시간)
- [ ] 한 씬 안에 한 비트만 있는가? (씬이 너무 많은 정보를 담지 않는가)
- [ ] 회차 클리프행어가 명확한가?
- [ ] 정보 누설/누락이 없는가? (시청자가 이 시점에 알면 안 되는 정보 / 알아야 하는 정보)

### 단계 2: 회차 간 교차 검수
새 회차가 완성될 때마다, 그 회차와 이전 회차들 사이의 일관성을 검수.

체크 항목:
- [ ] 인물 voice가 이전 회차와 일관되는가? (voice-guide 준수)
- [ ] 인물 간 호칭이 일관되는가? (변경 시 그것이 관계 변화의 신호인가)
- [ ] 인물 정보(나이·직업·관계·과거)가 이전 회차와 충돌하지 않는가?
- [ ] 이전 회차에 깐 빌드업 중 이번 회차에서 회수되는 것이 setup-payoff.md에 기록되었는가?
- [ ] 이번 회차에 새로 까는 빌드업이 setup-payoff.md에 추가되었는가?
- [ ] 시간선이 회차 간 일관되는가? (이번 회 사건이 저번 회 사건의 며칠/몇 주 뒤인지 명확한가)
- [ ] 세계관 룰을 어기지 않는가?
- [ ] 작품 톤에서 벗어나지 않는가?

### 단계 3: 전체 검수 (12회 완성 후 또는 의뢰 시)
모든 회차가 완성된 후, 또는 사용자 요청 시 실행.

체크 항목:
- [ ] 12회 안에 모든 메인 플롯이 해결되었는가?
- [ ] setup-payoff.md의 모든 빌드업이 회수 또는 의도된 미해결로 명시되었는가?
- [ ] 모든 주연 인물의 12부작 아크가 도착점에 도달했는가?
- [ ] 1회와 12회 사이에 의도된 미러링이 있는가?
- [ ] 작품 전체의 정서 곡선이 의도대로 흐르는가? (희망 → 절망 → 희망 등)
- [ ] 사용자에게 보고할 만한 작품 전체의 강점 3개, 약점 3개를 정리할 수 있는가?

## 자주 발견되는 버그 패턴

### 패턴 1: 호칭 드리프트
같은 인물이 같은 상대를 회차에 따라 다른 호칭으로 부른다.
- 예: EP01 "선배" → EP03 "오빠" → EP05 "선배" → EP08 "오빠"
- 정당화: 관계가 변하는 신호여야 함. 일관성 없는 변경은 버그
- 해결: 호칭 변경 회차와 그 회차에 있었던 관계 변화 사건을 매핑

### 패턴 2: 시간선 불일치
"내일 만나요"가 일주일 후 씬으로 이어진다.
- 정당화: 명시적 점프(자막 "1주일 후" 등)가 없으면 버그
- 해결: 회차마다 시간 흐름을 명시 (씬 헤더 또는 자막)

### 패턴 3: 인물 정보 미세 변경
EP01에서 "고향이 부산"이었는데 EP07에서 "어릴 적부터 서울에서 살았다"로 바뀜.
- 정당화: 거짓말이나 비밀이 아니라면 버그
- 해결: 인물 시놉시스의 고정값을 명확히 기록, 위반 시 보고

### 패턴 4: 빌드업 회수 누락
EP02에서 의미심장하게 등장한 소품이 12회까지 다시 나오지 않음.
- 정당화: 시청자에게 명시적으로 "그건 의미 없는 디테일이었다"고 알리는 방법은 없음. 시청자는 의미 있는 것으로 기억함
- 해결: 12회 안에 회수 또는 의도된 폐기 결정. 폐기 시 시청자 기억에 남지 않도록 그 소품의 비중을 사후 조정

### 패턴 5: 페이오프 정당화 부족
EP10에서 갑자기 인물이 새로운 기술을 가진 것으로 밝혀짐. 이전 회차에 빌드업 없음.
- 정당화: "데우스 엑스 마키나" — 시청자의 신뢰를 잃는 큰 버그
- 해결: 이전 회차에 짧은 빌드업 씬 추가 또는 페이오프 제거

### 패턴 6: 톤 일탈
어두운 미스터리 드라마에 갑자기 한 회차가 시트콤 톤
- 정당화: 의도된 분위기 환기일 수 있음. 그러나 작품 톤과 너무 떨어지면 위화감
- 해결: showrunner와 협의. 톤 일탈 정도를 줄이거나, 의도된 변주임을 작품 전체 구조에 반영

### 패턴 7: 정보 누설
EP04에서 시청자에게 EP10에 노출될 진실을 너무 일찍 알려줌.
- 정당화: 의도된 드라마틱 아이러니라면 OK
- 해결: 정보 노출 타이밍을 늦추거나, 모호하게 표현

## 검수 보고서 양식

```markdown
# EP{NN} 검수 보고서

작성: continuity-editor
날짜: {YYYY-MM-DD}
검수 단계: 단일 회차 / 회차 간 교차 / 전체

## 요약
- 검수 항목: {N}개
- 발견 이슈: {M}개 (HIGH {a} / MEDIUM {b} / LOW {c})
- 권고: {진행 가능 / 수정 후 진행 / 전면 재작업}

## 발견된 이슈

### ISSUE-{NN}-001
- 분류: 인물 일관성
- 심각도: HIGH
- 위치 A: EP07 S15 — "지수: 우리 엄마는 부산 사람이라…"
- 위치 B: EP01 S03 — "지수: 어릴 적부터 서울에서 컸어요"
- 문제: 지수의 가족 배경이 회차 간 모순됨
- 옵션:
  1. EP01의 대사를 "어머니 따라 서울로 왔다"로 수정 (가장 비용 적음)
  2. EP07의 대사를 다른 가족 사정으로 수정
  3. 인물 시놉시스의 가족 배경을 재정의
- 추천: 옵션 1. 인물 시놉시스의 "어머니가 부산 출신"을 유지하고, 본인의 서울 거주는 어머니 따라온 것으로 자연스럽게 처리
- 담당: dialogue-writer (EP01 대사 수정)

### ISSUE-{NN}-002
...

## 빌드업-페이오프 상태
- 이 회차에서 회수된 빌드업: SP-003, SP-007
- 이 회차에서 까는 빌드업: SP-014 (검찰청 보안 출입증)
- 미회수 OPEN 빌드업: SP-001, SP-005, SP-009, SP-011 (모두 12회까지 회수 예정)

## 권고
{회차 진행 가능 여부와 핵심 수정 사항}
```

## 검수자의 어조

검수 보고는 친절하고 구체적이어야 한다. 다른 팀원의 사기를 떨어뜨리지 않으면서도 발견을 명확히 전달한다.

### 좋은 어조
- "EP07 S15의 지수 대사가 EP01 S03과 충돌합니다. 옵션 3개 제안드립니다."

### 나쁜 어조
- "이건 명백한 오류입니다. 어떻게 이걸 놓쳤죠?"

검수자는 비판자가 아니라 협력자다.

## 후속 작업

이전 검수 로그가 존재하면:
1. `_workspace/review/continuity-log.md` Read
2. 이전 이슈 중 해결된 것을 CLOSED로 마킹
3. 새 산출물(추가/수정된 회차)만 신규 검수
4. 같은 패턴의 버그가 반복되면(예: 시간선 불일치가 3회 이상 발견) 패턴 보고
5. 미해결 이슈는 OPEN 상태 유지, 발견 횟수 카운트
