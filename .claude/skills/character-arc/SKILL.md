# Character Arc — 인물 설계 스킬

12부작 드라마의 인물을 입체적으로 설계한다. 외형이 아니라 결핍에서, 설정이 아니라 욕망에서 인물을 빌드한다.

## 인물의 5층 구조

좋은 드라마 인물은 다음 5층을 모두 갖춰야 한다.

```
┌─ 5. 변화 곡선 (12부작 아크)
├─ 4. 모순 (이중성)
├─ 3. 욕망과 두려움
├─ 2. 결정적 과거 (왜 이 사람이 되었는가)
└─ 1. 외형/배경 (가장 표층)
```

설정만 적으면 1층까지만 있는 인물이 된다. 5층까지 모두 채워야 살아 움직인다.

## 주연 인물 시놉시스 표준 양식

```markdown
# {역할명} — {배우 가이드 또는 한 줄 정의}

## 1. 외형/배경
- 나이/성별/직업/거주지
- 가족 구성
- 학력/경력 핵심
- 외모의 특징적 디테일 (한 가지면 충분)

## 2. 결정적 과거 (Origin)
{이 인물의 현재를 만든 단 하나의 사건. 보통 어린 시절. 직설적으로 서술하지 말고 장면으로 묘사}

## 3. 욕망과 두려움
- **표층 욕망**: {본인이 의식적으로 추구하는 것 — 승진, 복수, 사랑 등}
- **심층 욕망**: {본인도 잘 모르는 진짜 원하는 것 — 인정, 용서, 안전 등}
- **두려움**: {어떤 상황을 피하려고 하는가}
- **표층/심층의 거리**: {둘이 얼마나 어긋나는가 — 거리가 클수록 아크 가능성}

## 4. 모순 (이중성)
{이 인물의 모순적 면모. 정의롭다 + 비겁하다 / 다정하다 + 차갑다 등}
{모순이 없는 인물은 평면이다}

## 5. 12부작 아크
- 출발점 (1회 등장 시): {결핍과 욕망의 상태}
- 미드포인트 (6-7회): {시각이 바뀌는 사건}
- 도착점 (12회): {변화의 결과 또는 변화 거부의 결과}
- 변화 트리거: {무엇이 변화를 강제했는가 — 사건? 인물? 진실?}

## 6. 말투/목소리 (voice-guide 발췌)
- 어휘 톤: {일상어 / 한자어 / 전문어 / 비속어 비율}
- 문장 길이: {짧고 끊는다 / 길고 우회한다}
- 어미: {-요체 / -해체 / 반말}
- 침묵의 방식: {말을 자르고 응시 / 화제 전환 / 자조적 농담}
- 시그니처 말버릇 (있다면): {예: 결정적 순간에 "…그래요"}

## 7. 관계 요약 (간단)
- 주요 관계 1: {인물명}과 {관계 종류 + 정서 + 미해결 갈등}
- 주요 관계 2: ...
```

## 조연 인물 시놉시스 (간략형)

```markdown
# {역할명}

## 한 줄
{이 인물을 한 문장으로}

## 기능
{이 인물이 작품에서 수행하는 기능: 조력자 / 반대자 / 거울 / 정보원 / 분위기 메이커 등}

## 외형/배경
- 나이/직업 핵심
- 주요 인물과의 관계

## 핵심 특징 2-3개
- {특징 1}
- {특징 2}

## 12부작 내 등장 패턴
- 첫 등장: EP{N}
- 주요 비트: EP{N}, EP{N}, ...
- 퇴장 (있다면): EP{N}
```

조연은 1/2 페이지 이내로 압축한다. 조연을 주연만큼 깊게 쓰면 작품 무게중심이 흐려진다.

## 관계도 작성

### 텍스트 도식 양식

```markdown
# 관계도

## 핵심 관계 (작품의 척추)
```
         [도현(주인공)] ──사랑/오해──> [지수(여주)]
              │                              │
              │ 형                           │ 자매
              ↓                              ↓
         [재현(형)] ←──적대/혈연──> [윤(언니, 안타고니스트)]
              │
              │ 옛 동료
              ↓
         [수민(조력자)]
```

## 관계 종류 (선의 의미)
- 사랑 / 우정 / 가족 / 사제 / 동료 / 적대 / 미해결 채무 / 미해결 비밀

## 관계의 강도 (선의 굵기)
- 두꺼운 선: 작품 전체 갈등의 핵심 축
- 보통 선: 회차 단위 갈등에 영향
- 점선: 잠재적 관계 (아직 인물들이 모름)

## 미해결 갈등 표
| 인물 A | 인물 B | 갈등 | 회수 회차 (계획) |
|--------|--------|------|---------------|
| 도현 | 윤 | 13년 전 사고의 진실 | EP10 |
| 지수 | 윤 | 자매 간 모친 유산 분쟁 | EP07-08 |
| ... | ... | ... | ... |
```

### 관계도 작성 원칙
- 모든 주연 인물이 다른 모든 주연 인물과 어떤 관계인지 명시 (적어도 한 줄)
- 관계는 정적이지 않다 — 시작점과 변화 가능성을 같이 적는다
- 안 보이는 관계도 중요하다. 1회에 등장하지 않는 인물이 어느 회에 등장하는지 미리 표시

## 12부작 캐릭터 아크 추적표

```markdown
# Character Arc Tracker

| 인물 | EP1 상태 | EP4 상태 | EP7 (미드포인트) | EP10 상태 | EP12 도착점 |
|------|---------|---------|-----------------|----------|------------|
| 도현 | 차갑고 일에만 몰두 | 지수에게 균열 | 진실의 일부 알게 됨 | 동맹 선택 | 자신의 한계 수용 |
| 지수 | 밝지만 가짜 미소 | 도현에게 진실 일부 | 어머니의 비밀 알게 됨 | 어머니 용서 | 진짜 자기 인정 |
| 윤 | 완벽한 가면 | 가면에 균열 | 가면이 깨지기 시작 | 폭주 | 몰락 |
| 재현 | 변하지 않음 (의도된 정적 인물) | | | | |
```

### 아크 설계 원칙
- 모든 인물이 변할 필요 없다. 변하지 않는 인물은 변하는 인물의 거울이 된다
- 변화는 단계적 — 한 회에 갑자기 변하면 부자연스럽다. 미드포인트와 2막 끝이 자연스러운 분기
- 변화의 트리거는 외부 사건이 아니라 인물의 결정 — 사건은 결정을 강요하는 압력일 뿐

## voice-guide 작성

dialogue-writer가 회차 대본을 쓸 때 가장 자주 참조하는 문서. 모든 주연·조연 인물의 말투를 한 파일에 모은다.

```markdown
# Voice Guide

## 도현 (주인공)
- 어휘 톤: 한자어 비율 30%. 법률 용어가 일상에도 묻어남
- 문장 길이: 짧고 단정적. 한 호흡으로 끊는다
- 어미: -요체 기본. 친한 사이엔 반말이지만 격이 다른 반말 (예: "…그러게")
- 침묵의 방식: 시선만 주고 입을 다문다. 화제 전환은 거의 안 한다
- 시그니처: 결정의 순간에 "…알겠어요"라고 답하지만, 행동은 반대로 한다
- 안 쓰는 어휘: 비속어 거의 없음, 감탄사 적음

## 지수 (여주)
- 어휘 톤: 일상어. 가끔 영어 단어. 한자어는 의식적으로 피함
- 문장 길이: 길게 풀어 말함. 우회와 농담으로 진심을 가린다
- 어미: -요체와 -해체를 상대에 따라 자유롭게
- 침묵의 방식: 농담으로 분위기를 깬다
- 시그니처: 곤란할 때 "…그게요" 하며 시간 끌기
- 안 쓰는 어휘: 욕설, 비꼬는 한자어

## {조연들 — 짧게}
...
```

### voice-guide 작성 원칙
- 두 인물의 voice가 비슷하면 어미·어휘·문장 길이 중 적어도 하나는 의도적으로 분리
- 세대·계급·직업이 다르면 어휘 영역이 달라야 한다
- 시그니처 말버릇은 1-2개로 한정. 너무 많으면 캐리커처가 된다
- "안 쓰는 어휘"가 "쓰는 어휘"만큼 중요하다

## 매력적 안타고니스트 설계 ("장한석 효과")

전세계 흥행 K-드라마의 공통점: 안타고니스트가 시청자를 사로잡는다. 단순 악역이 아니라 시청자가 등장을 기다리는 입체적 인물.

### 글로벌 인기 안타고니스트 사례

| 안타고니스트 | 작품 | 매력의 핵심 |
|------------|------|----------|
| 장한석 | Vincenzo | 키덜트 광기 + 밀짚모자 + 시청자가 다음 등장을 기다림 |
| 박연진 | Glory | 우아한 외피 + 가해 부정 + 자기 합리화의 광기 |
| 김주영 | Sky Castle | 완벽한 외피 + 정체불명 + 마지막까지 모호한 진의 |
| 김두식 | Moving | 절제된 폭력 + 부성애의 흔적 + 적이지만 입체 |
| 프론트맨 | Squid Game | 가면 + 침묵 + 정체의 반전 |

### 매력적 안타고니스트의 5요소

| 요소 | 설명 |
|------|------|
| 1. 명확한 자기 논리 | 자신은 옳다고 믿는다. 시청자가 들었을 때 일리 있다고 느낌 |
| 2. 의외의 디테일 | 무서운 인물이 사랑하는 작은 것(취미·습관·약점) — 장한석의 밀짚모자, 김주영의 정체불명 미소 |
| 3. 카리스마 있는 외피 | 매력적인 외모·옷차림·말투. 시청자가 눈을 떼지 못함 |
| 4. 입체적 결핍 | 안타고니스트도 결핍에서 출발. 그 결핍이 공감 가능 (악인이 된 이유) |
| 5. 주인공의 거울 | 주인공과 거울처럼 닮은 부분. "왜 그가 그렇게 되었나"가 보임 |

### 안타고니스트 시놉시스 보강 양식

기본 5층 구조에 더해 안타고니스트는 다음 항목을 추가한다:

```markdown
## 자기 논리
{이 인물이 자기 행동을 어떻게 정당화하는가. 시청자가 일리 있다고 느낄 만한 논리}

## 의외의 디테일
{무서운 인물이 사랑하는 작은 것. 시청자가 그 디테일에 매료되어 기억함}

## 주인공과의 거울 관계
{이 인물의 어떤 면이 주인공과 닮았는가. "왜 그가 그렇게 되었나"의 답}

## 시그니처 등장 방식
{이 인물이 등장하는 방식의 시각·청각적 시그니처. 시청자가 그 등장을 기다리게 만드는 약속}
```

### 점검 질문
- 안타고니스트가 자기 행동을 어떻게 정당화하는가? 시청자가 들었을 때 일리 있다고 느끼는가?
- 안타고니스트에게 의외의 디테일이 있는가?
- 안타고니스트와 주인공이 어떤 면에서 닮았는가?
- 시청자가 안타고니스트의 등장을 기다릴 만한 시그니처가 있는가?

## 글로벌 K-드라마 트렌드: 여성 서사

2020년 이후 글로벌 K-드라마 인기작의 상당수가 여성 주인공의 복수·성장·연대 서사다. Glory, My Name, Mask Girl, Marry My Husband, Crash Landing, Itaewon Class의 조이서, Extraordinary Attorney Woo 등.

### 글로벌 흥행 여성 서사의 패턴

| 패턴 | 설명 |
|------|------|
| 수동 → 능동 | 피해자/피동적 위치에서 출발해 주체로 변화 |
| 여성 간 관계의 입체화 | 단순 라이벌이 아닌 복합적 관계 (Crash Landing의 두 여성) |
| 신체적·지적·감정적 능력 | 단지 의지가 아니라 구체적 기술·전략 (Glory의 18년 계획) |
| 로맨스의 선택지화 | 로맨스가 주제가 아닌 선택. 여성의 삶이 남성에 종속되지 않음 |

### 적용 가이드

이 트렌드는 **의무가 아닌 의식 점검**이다. 작품 톤에 맞을 때 적용한다.

**의식 점검 질문:**
- 작품의 여성 인물이 남성 인물에 종속되지 않고 자기 서사를 갖는가?
- 여성 인물의 능력이 구체적으로 보이는가 (단지 "강한 여자"가 아니라)?
- 여성 간 관계가 입체적인가 (단순 친구/라이벌이 아니라)?

> 작품이 의도적으로 다른 방향이라면 적용하지 않아도 된다. 단, 적용하지 않을 때도 그 이유를 의식적으로 판단할 것. 무의식적 누락은 글로벌 시청자에게 시대 뒤떨어진 작품으로 보일 위험.

상세 글로벌 흥행 요소는 `global-kdrama-elements` 스킬 참조.

## 점검 체크리스트

- [ ] 모든 주연 인물에 5층 구조가 다 채워져 있는가?
- [ ] 모든 주연 인물의 표층 욕망과 심층 욕망이 어긋나는가?
- [ ] 모든 인물에 모순적 면모가 적어도 하나 있는가?
- [ ] 모든 주연 인물의 12부작 아크가 명시되었는가 (또는 의도적으로 변하지 않음이 명시되었는가)?
- [ ] 관계도에서 모든 주연 간 관계가 정의되었는가?
- [ ] voice-guide에서 두 인물의 말투가 분간 가능한가?
- [ ] 조연이 너무 많지 않은가? (12부작 기준 주연 4-5 + 조연 5-8 권장)
- [ ] 안타고니스트가 5요소(자기 논리·의외의 디테일·카리스마·결핍·거울) 중 최소 3개를 갖는가?
- [ ] 여성 서사 트렌드를 의식적으로 점검했는가? (적용/미적용 모두 OK, 단 무의식적 누락은 금지)

## 후속 작업

이미 인물 자료가 있는 상태에서 호출되면:
- 인물 추가: 기존 관계도와 voice-guide에 통합. 기존 인물의 시놉시스는 건드리지 않음
- 인물 수정: 5층 중 어느 층의 수정인지 식별 → 표층(외형)이면 단독 수정, 심층(욕망/아크)이면 관계 인물과의 영향 점검
- 인물 통합: 두 조연을 합치는 경우 — 기능 통합 가능한지 확인 후 관계도 갱신
- voice-guide만 수정: 다른 자료에 영향 거의 없음, 단독 수정 가능
