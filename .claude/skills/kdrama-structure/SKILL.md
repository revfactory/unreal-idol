# K-Drama Structure — 12부작 구조 설계 스킬

12부작 한국 드라마의 구조를 설계한다. 12회라는 그릇 안에 인사이팅·1막·미드포인트·2막·클라이맥스·레졸루션을 어떻게 배치하는지가 작품의 호흡을 결정한다.

## 12부작의 표준 3막 구조

```
Act 1 (1-3회)  ──┐
                  │ ← 인사이팅 인시던트 (보통 1회 중반)
                  │ ← 1막 끝 (3회 끝 또는 4회 초)
Act 2 (4-9회)  ──┤
                  │ ← 미드포인트 (6-7회)
                  │ ← 2막 끝 (9회 끝 또는 10회 초)
Act 3 (10-12회)──┤
                  │ ← 클라이맥스 (11-12회)
                  └ ← 레졸루션 (12회 마지막)
```

회차 비율(3:6:3)은 정설이지만 작품에 따라 변주 가능하다. 단, 미드포인트가 6-7회에 오는 것은 거의 절대 룰이다 — 12회의 정확한 중간이 시청자의 몰입 분기점이다.

## 글로벌 OTT 시청자의 초반 후킹 (Pilot Hook)

글로벌 OTT 시청자는 첫 회, 심지어 첫 5분에 시청 지속 여부를 결정한다. 한국 본방 시청자 대비 인내심이 훨씬 짧다. **1-3회 설계는 글로벌 흥행의 가장 결정적 지점**이다.

### 3단계 후킹 구조

| 단계 | 시점 | 기능 | 점검 질문 |
|------|------|------|---------|
| 콜드 오프닝 | 첫 0-5분 | 작품의 톤·장르·세계관을 화면 한 장면으로 압축 | 첫 5분 안에 시청자가 "이건 ___ 드라마"라고 말할 수 있는가? |
| 첫 회 클리프행어 | 1회 끝 | 다음 회 시청 결정. "이 드라마의 약속" 드러냄 | 1회만 보고 끄지 못할 만한 강렬한 후크인가? |
| 3회 잠금 (3-Episode Lock) | 3회 끝 | 시청자가 "끝까지 보겠다"고 결정 | 3회 끝까지 봤을 때 작품의 본질적 약속이 모두 제시되었는가? |

### 전세계 흥행작의 콜드 오프닝 패턴

- **Squid Game 1회**: 어린 시절 무궁화 게임 회상 → 그 게임이 살인 게임으로 변형. 작품 본질을 5분 안에 압축
- **Mask Girl 1회**: 평범한 직장인이 밤마다 가면 쓰고 카메라 앞에 서는 모습. 이중생활을 즉시 노출
- **Vincenzo 1회**: 이탈리아 빌라에서 와인을 마시는 한국 남자. 그 빌라를 폭파. 장르 하이브리드 즉시 제시
- **Moving 1회**: 평범한 학생이 갑자기 하늘로 솟구치는 장면. SF 요소 즉시 노출
- **Glory 1회 첫 씬**: 어른이 된 주인공이 가해자 자녀의 학교에 부임. 과거-현재를 즉시 연결

공통점: **첫 5분에 작품의 본질이 화면으로 보인다.** 설명 없이 보여준다.

### 1-3회 설계 원칙
1. **1회 첫 5분에 작품 본질을 화면으로 보여라** — 대사 설명 없이
2. **1회 끝 클리프행어는 "이 작품의 약속"** — 단순 충격이 아닌, 작품이 무엇을 할 것인지의 약속
3. **3회 끝까지 작품의 핵심 사건 구도가 모두 등장** — 미스터리는 누군지, 멜로는 두 인물의 관계가 어디로 갈지, 안타고니스트는 누군지 노출 완료
4. **1-3회 페이싱은 일반 회차보다 빠르게** — 보통 회차의 1.2-1.5배 비트 밀도

> 작품이 글로벌 OTT를 노린다면 1-3회 설계에 가장 많은 시간을 투자하라. 글로벌 흥행 12요소 중 "초반 후킹"은 거의 모든 흥행작이 강 적용한 요소다. 상세는 `global-kdrama-elements` 스킬 참조.

## 회차별 기본 기능

| 회차 | 표준 기능 | 핵심 비트 후보 |
|------|----------|-------------|
| 1회 | 후크와 세계 소개 + 콜드 오프닝 | 인사이팅 인시던트, 주인공의 일상, 결정적 만남, 작품 본질 압축 |
| 2회 | 갈등 구도 명확화 | 안타고니스트 등장, 주인공의 거부, 1막 끝 결정 |
| 3회 | 1막 끝, 새로운 세계 진입 | 주인공이 일상을 떠나는 결정, 본격적 갈등의 시작 |
| 4회 | 2막 진입, 동맹과 적의 분화 | 조력자/적대자 구도 확립, 첫 번째 실패 |
| 5회 | 빌드업 가속 | 서브 플롯 본격화, 미드포인트 빌드업 |
| **6회** | **미드포인트 빌드업의 정점** | 의외의 진실 일부 노출, 큰 사건 임박 |
| **7회** | **미드포인트 폭발** | 게임 체인저 사건, 주인공의 목표 재설정 |
| 8회 | 새 국면 적응 | 변화된 환경에서의 갈등, 새로운 위협 등장 |
| 9회 | 2막 끝, 최악의 순간 | 주인공의 가장 어두운 순간, 가장 큰 상실 |
| 10회 | 3막 진입, 반격의 시작 | 잃었던 것을 되찾기 시작, 진짜 적 정체 드러남 |
| 11회 | 클라이맥스 도입 | 모든 빌드업의 회수 시작, 결정적 충돌 임박 |
| 12회 | 클라이맥스 + 레졸루션 | 최종 충돌, 변화의 도착점, 새로운 일상 |

## 클리프행어 설계

각 회 끝 클리프행어는 "다음 회의 약속"이다. 시청자가 다음 회를 보게 만드는 후크.

### 클리프행어의 유형
| 유형 | 효과 | 예시 |
|------|------|------|
| 정보 공개 | 진실의 일부 노출 | "엄마가 내 친모가 아니었다" |
| 위기 임박 | 곧 닥칠 위험 | "주인공이 함정에 빠진 순간 페이드" |
| 만남/재회 | 관계의 새 국면 | "사라진 줄 알았던 인물이 문 앞에" |
| 결단 | 인물의 큰 결정 | "주인공이 사표를 내는 손" |
| 정서적 폭발 | 감정의 극치 | 고백, 이별, 격분 |
| 미스터리 심화 | 새 의문 추가 | 단서가 새 미스터리를 부른다 |

### 클리프행어 작성 원칙
- 매 회 같은 유형의 클리프행어를 쓰지 말 것 — 무뎌진다
- 미드포인트(7회)와 2막 끝(9회)의 클리프행어는 가장 강력해야 한다
- 12회 끝은 클리프행어가 아니라 레졸루션 — 시청자의 만족스러운 한숨이 목표
- "충격을 위한 충격"은 금지. 인물의 욕망/갈등에서 자연스럽게 나와야 한다

## 빌드업과 페이오프

빌드업(setup)이란 시청자가 의식하지 못한 채 정보를 받아들이는 순간이고, 페이오프(payoff)란 그 정보가 결정적으로 작용하는 순간이다.

### 빌드업-페이오프 거리 (회차 간격)
| 거리 | 종류 | 예시 |
|------|------|------|
| 1-2회 | 짧은 호흡 | 1회 소품 → 2회 결정적 단서 |
| 3-5회 | 중간 호흡 | 3회의 말 → 8회의 의미 부여 |
| 6-9회 | 긴 호흡 | 1회의 어머니 대사 → 10회의 진실 |
| 10-11회 | 장대한 호흡 | 1회의 시작 장면 → 12회의 미러링 |

### 빌드업-페이오프 추적표 양식

```markdown
## Setup-Payoff Tracker

| ID | 빌드업 | 위치(빌드업) | 페이오프 | 위치(페이오프) | 상태 |
|----|--------|-----------|---------|-----------|------|
| SP-001 | 주인공의 어머니가 일본인이라는 단서 | EP01 S07 | 주인공의 정체성 핵심 | EP10 S32 | OPEN |
| SP-002 | 안타고니스트의 손 떨림 | EP03 S15 | 약물 중독 노출 | EP08 S22 | CLOSED |
| ... | ... | ... | ... | ... | ... |
```

12회 끝까지 OPEN 상태인 빌드업은 폐기되거나, 다음 시즌 떡밥이거나, 의도된 미해결이어야 한다. 정당화되지 않은 OPEN은 시청자에게 약속을 어긴 셈이 된다.

## 회차 트리트먼트 작성

각 회차 트리트먼트는 다음 양식을 따른다:

```markdown
# EP{N}: {회차 제목}

## 회차 한 줄 요약
{이 회는 무엇에 관한 회인가}

## A 플롯 / B 플롯
- A: {메인 사건 한 줄}
- B: {서브 사건 한 줄}

## 정서적 출발점 → 도착점
- 시작: {시청자가 회 시작 시 갖는 감정}
- 끝: {시청자가 회 끝에 갖는 감정}

## 비트 시퀀스 (6-10개)
1. **[오프닝/티저]** — 장소·등장인물·핵심 사건 (1-3줄)
2. **[전개1]** — ...
3. **[전환1]** — ...
4. **[빌드업]** — ...
5. **[미드 비트]** — 회차 안의 작은 미드포인트
6. **[복선]** — ...
7. **[클라이맥스 빌드]** — ...
8. **[회차 클라이맥스]** — ...
9. **[클리프행어]** — 다음 회의 후크

## 회수되는 빌드업
- SP-{ID}: {빌드업 설명} → {이 회의 어디에서 회수되는가}

## 새로 까는 빌드업
- SP-{새 ID}: {빌드업 설명} — {언제 회수 예정}

## 클리프행어 유형
- {정보 공개 / 위기 임박 / 만남 / 결단 / 정서 폭발 / 미스터리 심화}
```

## 한국 드라마 시청자의 기대 비트

K-드라마 시청자는 다음 비트를 기대한다. 모두 쓸 필요는 없지만, 의식적으로 변주하라.

| 비트 | 표준 위치 | 변주 옵션 |
|------|---------|---------|
| 첫 만남 | 1회 | 회상으로 처리, 늦은 만남 |
| 정체 노출 | 4-6회 | 일부만, 거꾸로, 잘못된 노출 |
| 첫 고백/접근 | 6-7회 | 회피된 고백, 우회된 고백 |
| 이별/오해 | 9-10회 | 짧은 오해, 의도된 이별 |
| 진실 회수 | 11회 | 부분 회수, 새 진실 추가 |
| 재회/결합 | 12회 | 열린 결말, 변형된 결합 |

> 변주의 핵심: 클리셰의 위치는 옮기고, 형태는 비틀어라. 완전히 없애면 K-드라마 문법에서 너무 멀어진다.

## 점검 체크리스트

작성된 12부작 아크와 회차 트리트먼트를 다음으로 점검:

- [ ] 12회 안에 모든 메인 플롯이 회수되는가?
- [ ] 미드포인트(6-7회)에 게임 체인저가 있는가?
- [ ] 9회 끝이 최악의 순간(전체 작품의 어두운 정점)인가?
- [ ] 각 회 클리프행어가 모두 다른 유형인가 (5회 이상 같은 유형 반복 금지)?
- [ ] 모든 빌드업이 12회까지 회수되거나, 의도된 미해결로 명시되는가?
- [ ] 1회와 12회에 미러링 비트가 있는가? (시작과 끝의 연결)
- [ ] 서브 플롯이 메인 테마를 변주하는가 (별개로 굴러가지 않는가)?
- [ ] 1회 첫 5분에 작품 본질을 압축한 콜드 오프닝이 있는가?
- [ ] 1회 끝 클리프행어가 "이 작품의 약속"을 드러내는가?
- [ ] 3회 끝까지 작품의 핵심 사건 구도가 모두 등장했는가?
- [ ] 회차 단위 완결성이 있는가? (회차마다 작은 질문 → 답)

이 11개 모두 OK여야 트리트먼트 단계를 종료한다.

## 후속 작업

이미 트리트먼트가 있는 상태에서 호출되면:
- 특정 회차 수정 요청 시: 해당 회차와 인접 ±2회의 비트 연결을 함께 점검
- 미드포인트 위치 변경 요청 시: 사실상 전체 재작성. 사용자에게 영향 설명 후 진행
- 클리프행어 강화 요청 시: 유형 다양성 점검부터
- 빌드업 추가 요청 시: setup-payoff 트래커 갱신 + 회수 위치 명확화
