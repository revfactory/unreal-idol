# K-Drama Bible — 작품 바이블 작성 스킬

12부작 한국 드라마의 작품 바이블 4종을 작성하는 스킬. 작품의 정체성을 한 자리에 모아 팀 전체의 참조 기준이 되게 한다.

## 작품 바이블의 4종

| 파일 | 길이 | 목적 |
|------|------|------|
| `logline.md` | 1줄 + 3-5문장 | 한 줄 로그라인과 후크 |
| `synopsis.md` | 1-2 페이지 | 전체 줄거리 |
| `tone-theme.md` | 1 페이지 | 톤·장르·테마·키워드·레퍼런스 |
| `world.md` | 0.5-1 페이지 | 세계관·시대·공간 |

이 4종이 작품의 모든 후속 결정의 근거가 된다.

## 1. logline.md

### 작성 양식

```markdown
# {작품 가제}

## 한 줄 로그라인
{1문장. 주인공이 누구이고, 무엇을 원하며, 무엇과 부딪치는가}

## 후크 (3-5문장)
{시청자가 채널을 멈추게 만드는 짧은 압축 줄거리. 인사이팅 인시던트와 결정적 갈등까지}

## 핵심 질문
{이 드라마가 시청자에게 던지는 한 가지 질문}
```

### 좋은 로그라인의 조건
- **주인공의 정체성 + 욕망 + 장애물** 세 요소가 들어간다
- 장르가 한 번에 읽힌다 (멜로/스릴러/오피스/사극 등)
- 듣는 사람의 머릿속에 한 장면이 떠오른다
- 30초 안에 말할 수 있다

### 예시
> "암기 시험에서 0점만 나오는 천재 검사가, 자신을 가둔 음모를 풀기 위해 기억을 잃은 척하는 도둑과 손을 잡는다."

좋은 로그라인의 특징: 주인공(천재 검사)의 정체성과 약점(시험 0점), 욕망(음모를 푸는 것), 장애물(도둑과 손을 잡아야 함)이 한 문장에 다 들어있다.

### 하이콘셉트(High-Concept) 로그라인 — 글로벌 흥행작의 공식

전세계 흥행 K-드라마의 거의 모두가 "하이콘셉트" 로그라인을 갖는다. 평범한 로그라인은 작품을 설명하지만, 하이콘셉트 로그라인은 작품을 **결정시킨다**.

**하이콘셉트의 3가지 패턴:**

1. **익숙함 + 낯섦의 충돌**
   - "어른들의 어린이 놀이 데스 게임" (Squid Game) — 어린이 놀이(익숙) × 살인(낯섦)
   - "이탈리아 마피아 한국 변호사가 시골 상가를 지킨다" (Vincenzo) — 마피아(익숙) × 한국 시골(낯섦)

2. **즉시 떠오르는 한 장면**
   - "북한군 장교가 우연히 만난 남한 재벌녀를 호위해 38선을 넘는다" (Crash Landing)
   - "보라색 운동복을 입은 어른들이 무궁화 꽃이 피었습니다를 한다" (Squid Game 핵심 이미지)

3. **갈등 본질의 한 단어 화**
   - "학교 폭력 피해자가 18년을 살아 가해자 자녀의 담임이 되어 그녀의 집에 들어간다" (Glory) — 복수
   - "외모 콤플렉스의 평범한 여자가 인터넷 BJ가 되며 살인을 저지른다" (Mask Girl) — 정체성/이중성

**평범한 로그라인 vs 하이콘셉트:**

| 평범 | 하이콘셉트 |
|------|---------|
| "사랑하는 두 사람이 운명을 헤쳐나가는 멜로" | "북한군 장교가 우연히 만난 남한 재벌녀를 호위해 38선을 넘는다" |
| "학교 폭력 피해자가 복수하는 이야기" | "학교 폭력 피해자가 18년을 살아 가해자의 자녀 담임으로 그녀의 집에 들어간다" |
| "재벌가의 비밀을 다룬 가족극" | "외모 콤플렉스의 평범한 여자가 인터넷 BJ가 되며 살인을 저지른다" |

**하이콘셉트 점검 질문:**
- 로그라인을 30초 안에 말했을 때 듣는 사람의 눈이 커지는가?
- 그 작품을 안 봐도 한 장면이 떠오르는가?
- 외국인 친구에게 자막으로 추천할 때 한 줄로 설명 가능한가?

작품이 글로벌 OTT를 노린다면 하이콘셉트는 거의 필수다. 단, 작품성 우선·일상극·잔잔한 멜로에서는 의도적으로 하이콘셉트를 포기할 수 있다 (예: Reply 1988, My Liberation Notes). 그 경우는 **테마의 정서적 깊이**가 하이콘셉트를 대체한다.

> 글로벌 흥행 12요소 전반은 `global-kdrama-elements` 스킬 참조.

## 2. synopsis.md

### 작성 양식

```markdown
# 시놉시스 — {작품 가제}

## 1막 (1-3회)
{도입부. 주인공의 일상 → 인사이팅 인시던트 → 1막 끝의 결정}

## 2막 (4-9회)
{본격 갈등. 빌드업과 반전, 미드포인트 충격, 점진적 압박}

## 3막 (10-12회)
{클라이맥스와 레졸루션. 진실 노출, 최종 결단, 변화의 도착점}

## 결말의 정서
{시청자가 마지막 장면에서 느낄 단 하나의 감정}
```

### 시놉시스 작성 원칙
- **회차별이 아니라 막 단위로 서술** — 회차 트리트먼트는 plot-architect의 영역
- 1-2 페이지가 적정. 너무 짧으면 모호하고, 너무 길면 트리트먼트가 된다
- 모든 주연 인물의 핵심 동선이 드러나야 한다
- 결말을 미리 적되, 결말 자체보다 결말의 **정서**가 더 중요하다

## 3. tone-theme.md

### 작성 양식

```markdown
# 톤·테마·장르

## 장르 하이브리드
- 주 장르: {예: 미스터리 멜로} — 시청자가 "이건 ___ 드라마"라고 한 단어로 말할 수 있어야 함
- 부 장르: {예: 가족극} — 주 장르를 강화하는 방향
- 하이브리드의 화학반응: {두 장르의 결합이 만드는 작품 고유의 톤. 부 장르를 빼면 작품이 평범해지는가? 평범해진다면 하이브리드 성공}

## 톤
- 분위기: {예: 차분하고 서늘하나, 인물 사이엔 따뜻한 균열}
- 영상 톤 키워드: {예: 푸른 새벽, 비 오는 도시, 따뜻한 실내등}
- 음악 톤: {예: 미니멀 피아노, 가끔 신스 페이드인}

## 테마 (한 줄 + 부연)
{작품이 묻는 질문. 모든 인물과 갈등이 이 질문을 다른 각도에서 변주한다}

## 서브 테마 2-3개
- {서브 테마 1}
- {서브 테마 2}

## 핵심 키워드 (5-7개)
{기억, 용서, 빚, 거짓말, 새벽, 약속 등}

## 레퍼런스 작품과 차별점
- 참고 1: {작품명} — {참고하는 부분}
- 참고 2: ...
- 우리의 차별점: {이 작품이 그 작품들과 어떻게 다른가}

## 금기 (안 할 것 목록)
- {예: 과한 우연으로 인한 만남}
- {예: 폭력적 묘사}
- {예: 갈등의 손쉬운 해소}
```

### 톤 작성 원칙
- "재미있다", "감동적이다" 같은 모호한 형용사는 금지. 구체적 이미지·소리·색으로 묘사
- 레퍼런스는 2-3편으로 한정. 너무 많으면 정체성이 흐려진다
- 차별점이 가장 중요하다. "어떤 작품 + 어떤 작품의 결합"으로 표현되면 안 된다
- 금기 목록은 팀원들이 작품의 색을 지키는 가드레일이 된다

### 장르 하이브리드 설계

전세계 흥행 K-드라마의 거의 모두가 두 장르 이상을 의식적으로 결합한다. 단일 장르 작품은 글로벌 OTT에서 묻히기 쉽다.

**대표 하이브리드 패턴:**
| 결합 | 사례 |
|------|------|
| 멜로 + 스릴러 | Crash Landing on You, While You Were Sleeping |
| 멜로 + 판타지 | Goblin, My Love from the Star |
| 코미디 + 범죄 | Vincenzo, Extraordinary Attorney Woo |
| 휴먼 + SF | Moving, Mr. Sunshine |
| 복수극 + 사회극 | Glory, Sky Castle |
| 일상 + 의학 | Hospital Playlist |

**설계 원칙:**
1. **주 장르는 한 가지로 명확히** — 시청자가 "이건 ___ 드라마"라고 한 단어로 분류 가능해야 함
2. **부 장르는 주 장르의 한계를 보완하는 방향으로** — 단순 양념이 아니라 화학 반응
3. **부 장르를 빼면 평범해질 정도여야 성공** — Vincenzo에서 코미디를 빼면 평범한 범죄극, 코미디를 빼지 않으면 시그니처

작품이 글로벌 OTT를 노린다면 장르 하이브리드는 거의 필수.

## 4. world.md

### 작성 양식

```markdown
# 세계관·배경

## 시대
{예: 2026년 한국. 동시대지만 통신 인프라가 약간 발전한 근미래}

## 공간
- 메인 공간: {예: 서울 마포구의 5층짜리 검찰지청 건물}
- 서브 공간: {예: 한강변 다리 밑 노숙자 캠프, 강북의 24시간 식당}
- 공간의 정서: {각 공간이 작품 정서에 기여하는 방식}

## 사회/직업적 디테일
- 직업 묘사의 기준: {예: 현직 검사의 자문을 받은 사실적 묘사. 단, 절차의 과도한 디테일은 생략}
- 사회 분위기: {예: 청년층의 불안감, 정치적 양극화}

## 작품 고유의 룰 (있는 경우)
{판타지/SF 요소가 있다면 그 작동 원리. 없으면 "현실 기반"으로 명시}
```

### 세계관 작성 원칙
- 현대 드라마라도 "그 작품 안의 한국"은 미세하게 다르다 — 어떤 디테일이 강조되고 어떤 게 생략되는지 명시
- 직업물이라면 사실성의 수준을 정해둔다 (정확도 100% vs 시청자 친화 70%)
- 작품 고유 룰은 한 번 정하면 끝까지 어기지 않는다. 룰의 균열은 시청자 이탈로 직결

## 작성 순서

순서대로 작성하되, 뒤 단계에서 앞 단계로 돌아가 보정한다.

1. **로그라인 한 줄** — 가장 먼저, 가장 짧게
2. **테마 정의** — 작품의 척추
3. **장르·톤** — 척추 위의 살
4. **시놉시스** — 척추를 따라 펼쳐지는 이야기
5. **세계관** — 이야기가 펼쳐질 무대

작성 중 톤과 시놉시스가 충돌하면 톤이 우선이다. 톤은 작품 정체성, 시놉시스는 그 정체성의 한 가지 구현일 뿐.

## 5. global-priorities.md (신규)

작품의 글로벌 시청자 타겟팅 강도를 결정하고, 12개 글로벌 흥행 요소 중 본 작품의 우선순위를 명시한다.

```markdown
# 글로벌 흥행 우선순위

## 타겟팅 모드
{글로벌 OTT 메인 / 국내 중심 + 해외 부가 / 작품성 우선·시상식 노림 / 의도된 로컬}

## 12개 요소별 적용 강도

| # | 요소 | 적용 강도 | 이유 |
|---|------|---------|------|
| 1 | 하이콘셉트 로그라인 | 강 / 중 / 약 | {본 작품에서 이 요소를 왜 이 강도로 적용하는가} |
| 2 | 장르 하이브리드 | 강 / 중 / 약 | |
| 3 | 초반 후킹 | 강 / 중 / 약 | |
| 4 | 매력적 안타고니스트 | 강 / 중 / 약 | |
| 5 | 여성 서사 트렌드 | 강 / 중 / 약 | |
| 6 | K-aesthetic 의식적 활용 | 강 / 중 / 약 | |
| 7 | 한국 정서의 보편화 | 강 / 중 / 약 | |
| 8 | 사회 비판 보편화 | 강 / 중 / 약 | |
| 9 | 자막 친화 대사 | 강 / 중 / 약 | |
| 10 | OST·시그니처 음악 | 강 / 중 / 약 | |
| 11 | 회차 완결성 + 시리즈 완결성 | 강 / 중 / 약 | |
| 12 | 시즌제·확장 가능성 | 강 / 중 / 약 | |

## 강 적용 요소 (필수 점검)
{이 작품의 글로벌 흥행을 좌우할 핵심 3-5개 요소}

## 약 적용 / 미적용 요소 (의도된 포기)
{본 작품의 색에 맞지 않아 의도적으로 약하게 또는 적용하지 않는 요소와 이유}
```

> 12개 요소 상세는 `global-kdrama-elements` 스킬 참조.

## 사용자 검토 단계

바이블 5종 작성 후 사용자에게 반드시 다음 4가지를 확인받는다:

1. **한 줄 로그라인이 매력적인가?** — 시청자가 듣고 보고 싶다고 느끼는가. 하이콘셉트인가?
2. **테마 한 문장이 작품의 척추로 충분한가?** — 12부작을 관통할 무게가 있는가
3. **금기 목록이 누락 없는가?** — 작품에서 절대 보고 싶지 않은 것
4. **글로벌 우선순위가 명확한가?** — 강 적용 요소가 의식적으로 선택되었는가

이 넷이 OK여야 다음 Phase로 넘어간다.

## 후속 작업

이미 바이블이 있는 상태에서 재호출되면:
- 사용자가 어느 항목 수정을 원하는지 식별
- 톤 수정 시 시놉시스에 파급되는지 점검 (대부분 파급된다)
- 테마 수정 시 사실상 새 작품 — 전면 재작성 제안
- 세계관 부분 보강은 다른 항목에 거의 파급되지 않음, 단독 수정 가능
