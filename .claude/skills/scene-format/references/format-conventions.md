# 한국 드라마 대본 포맷 상세 관행

## 화면 종류 전체 목록

| 표기 | 의미 |
|------|------|
| 외경 | 건물 밖, 야외 |
| 내경 | 실내 |
| (생략) | 헤더에 표기 없으면 내경으로 간주 |
| (D) | Day (낮) |
| (N) | Night (밤) — 시간대 표기와 중복 시 생략 |
| (꿈) | 꿈 장면 |
| (회상) | 과거 회상 |
| (환상) | 인물의 환각/상상 |
| (CCTV 화면) | CCTV 시점 |
| (TV 화면) | TV 안 화면 |
| (PC 화면) | 컴퓨터 화면 |
| (휴대전화 화면) | 휴대폰 화면 |
| (인터컷) | 두 장소를 교차 편집 |

## 약속 기호 확장

| 기호 | 의미 |
|------|------|
| `…` | 말끝 흐림, 침묵 |
| `─` | 말 끊김 (다른 인물 끼어듦) |
| `!` | 큰 소리 |
| `?!` | 놀라움 + 의문 |
| `...!` | 침묵 후 큰 소리 |
| `(E)` | Effect — 화면 밖 목소리 |
| `(O.L)` | Overlap — 대사 겹침 |
| `(O.S)` | Off Screen — 화면 밖 등장 |
| `(V.O)` | Voice Over — 보이스오버 |
| `(N)` | 내레이션 |
| `(독백)` | 인물의 혼잣말 |
| `(생각)` | 마음의 소리 (자막 또는 V.O 처리) |
| `(F)` | Filter — 전화기 너머 음성 등 필터링된 소리 |
| `(F.B)` | Flashback — 플래시백 |
| `(F.F)` | Flash Forward — 미래 예지 |

## 인물명 표기

- **본명** — 평상시
- **{직책+성씨}** — 직장에서 (예: "박 검사", "이 변호사")
- **{소리}** — 화면에 안 보이고 소리만 (예: "지수(E)")
- **{N명}** — 군중 (예: "기자들 N명")
- **{역할}** — 단역 (예: "편의점 알바", "택시기사")

## 지문에서 자주 쓰이는 표현

### 동작 묘사
- "한 발 뒤로 물러선다" (놀람/거부)
- "고개를 천천히 든다" (각오/결심)
- "시선을 떨군다" (회피/슬픔)
- "입가에 미세한 미소" (속내 숨김)
- "손이 굳는다" (충격)
- "긴 숨을 내쉰다" (체념/안도)

### 분위기 묘사
- "공기가 한순간 식는다"
- "어색한 정적이 흐른다"
- "사이"
- "서로의 시선이 닿는다"
- "방 안의 시간이 멈춘다"

### 시각적 전환
- "화면이 천천히 어두워진다 → 페이드 아웃"
- "다음 씬으로 디졸브"
- "동시 컷 — 두 인물 같은 행동"

## 시간대 표기 변형

| 표기 | 시간 추정 |
|------|---------|
| 새벽 | 04:00-06:00 |
| 이른 아침 | 06:00-08:00 |
| 아침 | 08:00-10:00 |
| 오전 | 10:00-12:00 |
| 점심 무렵 | 12:00-13:00 |
| 낮 | 13:00-17:00 |
| 늦은 오후 | 17:00-18:00 |
| 저녁 | 18:00-20:00 |
| 밤 | 20:00-23:00 |
| 심야 | 23:00-04:00 |

같은 회차 내에서 시간 흐름을 추적 가능하게 표기. continuity-editor가 시간선 검수 시 이 표기를 참조.

## 회차 분량 가이드

- 60분 미니시리즈 (KBS, MBC, SBS): 60-70 페이지
- 70분 미니시리즈 (tvN, JTBC): 70-80 페이지
- 80분 회차 (스트리밍 작품): 80-90 페이지

페이지 환산 기준: A4, 신명조 11pt 또는 한컴 명조 10pt, 줄 간격 160%. 한 페이지 약 1분 분량.

## 대본 표지 관행

회차 첫 페이지에 다음 정보를 포함하기도 한다 (필수는 아님):

```
{작품 제목}
EP{N} — {회차 제목}

작/연출: {이름}
초고 작성일: {YYYY-MM-DD}
회차 분량: {N} 페이지 / 약 {N}분
```

## 한국 드라마 대본 vs 영화 시나리오 차이

| 항목 | 한국 드라마 대본 | 영화 시나리오 |
|------|-----------------|--------------|
| 씬 헤더 | `S#N. 장소 / 시간 / 외경` | `INT. LOCATION - DAY` |
| 지문 시제 | 현재시제, 간결문 | 현재시제, 묘사적 |
| 분량 단위 | 페이지 ≈ 1분 | 페이지 ≈ 1분 (동일) |
| 약속 기호 | 한국식 (E, O.L 등) | 영어식 (V.O, O.S 등) |
| 작가 비중 | 거의 절대적 (작가가 곧 작품) | 감독·각본가 분업 |

드라마는 작가 주도. 따라서 대본의 디테일이 곧 작품의 디테일이다. 영화처럼 "감독이 알아서 할 부분"이라며 비우면 안 된다. 단, 컷 분할까지 지정하면 월권.
