# Scene Format — 한국 드라마 대본 표준 포맷

한국 드라마 대본은 영화 시나리오와 다른 자체 관행을 갖는다. 이 스킬은 그 포맷을 정의한다.

## 씬 헤더 표준

```
S#1. 한강공원 산책로 / 새벽 / 외경
[등장: 지수, 도현]
```

### 헤더의 4요소
| 요소 | 의미 | 예시 |
|------|------|------|
| `S#N` | 씬 번호 (회차 내 순번) | S#1, S#42 |
| 장소 | 구체적 공간명 | 한강공원 산책로, 도현의 사무실 |
| 시간 | 새벽/아침/낮/저녁/밤/심야 | 새벽, 밤 |
| 화면 종류 | 외경(외부)/내경(내부)/(생략 가능) | 외경, 내경 |

### 등장 인물 표기
헤더 다음 줄에 `[등장: 이름1, 이름2, ...]` 형식으로 명시. 그 씬에 실제로 등장하는 인물만 포함. 목소리만 나오는 경우는 `(소리)` 표기.

### 회상/꿈/CCTV 등 특수 화면
헤더 끝에 추가 표기:
```
S#15. 도현의 집 / 침실 / 밤 (꿈)
S#22. 검찰청 복도 / 낮 (회상, 13년 전)
S#37. 골목 CCTV 화면 / 새벽
```

## 지문 작성 규칙

### 기본 원칙
- **현재시제, 간결문** — 한국 드라마 대본 관행
- **인물의 감정을 직접 서술하지 않음** — "슬프다", "기쁘다"가 아니라 행동·표정·환경으로 보여줌
- **단락은 짧게** — 한 단락 2-4문장. 화면이 바뀌면 새 단락
- **카메라 지시는 최소한** — 핵심 시점만. 모든 컷을 지정하면 연출자의 영역 침범

### 좋은 지문 예시

```
S#1. 한강공원 산책로 / 새벽 / 외경
[등장: 지수, 도현]

새벽 안개 사이로 조깅하는 지수. 헤드폰을 끼고 있다.
반대편에서 도현이 다가온다. 둘의 시선이 스친다.

지수, 발을 잠시 멈춘다. 도현도 멈춘다.

(C.U) 지수의 손가락이 헤드폰 줄을 꽉 쥔다.
```

### 나쁜 지문 예시 (감정 직설)
```
지수는 도현을 보고 너무 놀라고 무서웠다. 13년 전의 그 사건이 떠올라서 심장이 두근거렸다.
```
→ 위 내용을 보여주려면:
```
지수, 도현을 본 순간 발이 굳는다. 헤드폰 줄을 쥔 손이 떨린다.
(짧은 인서트) 13년 전 — 어둠 속 한 줄기 라이트, 비명.
지수, 한 발 뒤로 물러선다.
```

## 대사 작성 양식

```
지수
(헤드폰 한쪽을 빼며)
…여기서 보네요.

도현
(잠깐 멈춰서)
저도 오늘 처음이에요.

지수
(웃을 듯 말 듯)
그래요. 저도. 처음.

(잠시 정적. 둘 다 지나친다.)

지수, 한 발 멈춰 뒤를 돌아본다.
```

### 대사 구조
1. **인물명** — 줄 가운데 또는 왼쪽 정렬 (보통 왼쪽)
2. **(괄호 안 동작/표정)** — 대사 전 또는 대사 중간에 짧게
3. **대사 본문** — 인물명 아래 줄

### 약속 기호
| 기호 | 의미 |
|------|------|
| `…` | 말끝을 흐림, 침묵, 망설임 |
| `─` | 말을 끊김 (다른 인물이 끼어듦) |
| `!` | 큰 소리, 외침 |
| `?!` | 놀라움 + 의문 |
| `(E)` | 화면 밖 목소리 (인물은 안 보임) |
| `(O.L)` | 오버랩 (대사 겹침) |
| `(F.B)` | 플래시백 |
| `(N)` | 내레이션 |
| `(생각)` | 마음의 소리, 자막 처리 |

### 사용 예시
```
도현
당신이 그때 거기 있었던 거 ─

지수
(말을 끊고)
잘못 본 거예요.

도현
(E, 휴대전화 너머)
지금 어디예요?
```

## 씬 리스트 양식

회차 전체의 씬을 한눈에 보는 문서. scene-director가 트리트먼트를 씬으로 분해한 직후 작성.

```markdown
# EP01 Scene List — {회차 제목}

| S# | 장소 | 시간 | 등장 인물 | 비트 요약 | 비고 |
|----|------|------|----------|---------|------|
| 1 | 한강공원 산책로 | 새벽 | 지수, 도현 | 첫 스침. 지수의 동요 | 인사이팅 빌드업 |
| 2 | 지수의 집 / 침실 | 아침 | 지수 | 악몽에서 깸. 13년 전 단서 인서트 | (F.B) 사용 |
| 3 | 검찰청 / 도현 사무실 | 낮 | 도현, 재현 | 도현이 새 사건 배정 받음 | A 플롯 진입 |
| 4 | 카페 / 외부 테라스 | 낮 | 지수, 윤 | 자매 간 미세한 균열 | B 플롯 시작 |
| ... | ... | ... | ... | ... | ... |

## 회차 통계
- 총 씬 수: {N}
- 외경/내경 비율: {외경 N개 / 내경 N개}
- 시간대 분포: 새벽 N, 아침 N, 낮 N, 저녁 N, 밤 N, 심야 N
- 회차 핵심 비트가 모두 분해되었는가: ☐ 확인
- 클리프행어 씬은 어느 것: S#{N}
```

### 씬 리스트 작성 원칙
- 한 회차 40-70씬이 적정. 70씬 초과 시 압축 또는 이월 검토
- 짧은 씬(1분 이내)과 긴 씬(3-5분)을 의도적으로 교차
- 시간대 분포를 의식 — 한 회가 새벽 → 아침 → 낮으로만 흐르면 단조롭다
- 한 씬에 한 비트. 한 씬에 두 비트를 우겨넣지 말 것

## 씬 지문 초안 양식 (대사 placeholder 포함)

scene-director가 씬 분해 후 각 씬을 개별 파일로 작성. 대사 부분은 dialogue-writer가 채우게 비워둔다.

```markdown
S#1. 한강공원 산책로 / 새벽 / 외경
[등장: 지수, 도현]

새벽 안개 사이로 조깅하는 지수. 헤드폰을 끼고 있다.
반대편에서 도현이 다가온다. 둘의 시선이 스친다.

지수, 발을 잠시 멈춘다. 도현도 멈춘다.

지수
{대사 placeholder: 가벼운 인사를 가장하지만 동요}

도현
{대사 placeholder: 거리감 있는 응답}

(C.U) 지수의 손가락이 헤드폰 줄을 꽉 쥔다.

지수
{대사 placeholder: 더 가벼워지려 애쓰는 한마디}

(잠시 정적. 둘 다 지나친다. 지수, 한 발 멈춰 뒤를 돌아본다.)

---

## 씬 메타
- 비트 기능: 인사이팅 빌드업, 두 주인공의 첫 스침
- 정서 가이드: 표면은 우연한 만남, 내면은 13년 전의 그림자
- 회수되는 빌드업: 없음 (이 씬이 SP-001의 발단)
- 까는 빌드업: SP-001 (둘의 과거 연결)
```

## 대본(완성본) 양식

dialogue-writer가 씬 지문 placeholder를 대사로 채워 완성한다. 회차 전체를 한 파일에 모은다.

```markdown
# EP01 — {회차 제목}

작성: 드라마 팀
회차 분량 가이드: 60-70페이지 (60-70분 분량)

---

S#1. 한강공원 산책로 / 새벽 / 외경
[등장: 지수, 도현]

(씬 본문)

S#2. 지수의 집 / 침실 / 아침
[등장: 지수]

(씬 본문)

...

S#67. 도현의 사무실 / 심야 / 내경 (회차 마지막 씬)
[등장: 도현, 재현(E)]

(씬 본문)

도현
(전화기를 천천히 내려놓으며)
…그게 사실이라면.

(어둠. 페이드 아웃.)

— EP01 끝 —
```

| 표기 | 의미 |
|------|------|
| (C.U) | 클로즈업 |
| (Big C.U) | 익스트림 클로즈업 |
| (롱샷) | 멀리서 잡음 |
| (인서트) | 짧은 삽입 화면 |
| (몽타주) | 빠르게 이어지는 짧은 장면들 |
| (디졸브) | 부드러운 전환 |
| (페이드 인/아웃) | 화면이 서서히 나타남/사라짐 |
| (점프 컷) | 의도적 끊김 편집 |

## 점검 체크리스트

씬 리스트와 대본을 다음으로 점검:

- [ ] 모든 씬에 헤더(S#, 장소, 시간) + 등장인물이 명시되었는가?
- [ ] 지문이 현재시제, 간결문인가?
- [ ] 인물의 감정을 직접 서술한 곳은 없는가?
- [ ] 약속 기호(`…`, `─`, `(E)` 등)가 일관되게 쓰였는가?
- [ ] 한 회차의 씬 수가 40-70개 범위인가?
- [ ] 짧은 씬과 긴 씬이 교차되는가?
- [ ] 회차 마지막 씬이 클리프행어인가?
- [ ] 회상/꿈/CCTV 등 특수 화면이 헤더에 명시되었는가?

상세 약속 기호 전체 목록과 화면 종류 변형은 `references/format-conventions.md` 참조.

## 방송 표준 포맷 — 마크다운 금지 사항 (중요)

본 스킬은 *방송용 미니시리즈 대본*을 다룬다. README나 기술 문서가 아니다. 다음 마크다운 요소는 대본에 **사용 금지**:

| 금지 요소 | 대체 방법 |
|---------|---------|
| `**굵게**` | 평문으로. 의도적 강조는 *작은따옴표* 또는 `(C.U)`·`(강조)` 같은 지문 표기로 |
| `*기울임*` (단어 강조용) | 작은따옴표 `'강조어'` 또는 평문으로. 단 *작가의 결정적 강조*는 작은따옴표가 표준 |
| `---` (씬 구분선) | `(컷)` + 한 줄 빈 줄. 다음 씬은 `S#N+1.` 헤더로 자연 시작 |
| `#`, `##` 등 마크다운 헤더 | 씬 헤더는 `S#N.` 형식만. 큰 단락 구분은 줄바꿈으로 |
| `> 인용` | 인용 형식 자체가 대본에 부적합. 인물 발화는 대사 블록으로 |
| 목록 마커 (`-`, `*`, `1.`) | 지문은 평이한 산문체. 목록이 필요하면 별도 인서트 처리 |

## 대사 블록 표준 (3단 구조)

```
        지수
   (E. 작게)
   ...오늘 밤 비 온대.
```

**구조 원칙:**
- **1행**: 인물명만. 들여쓰기(공백 8칸 또는 탭 1칸). 굵게 금지.
- **2행 (선택)**: 정서지문·연기 지문. 들여쓰기 4칸, 괄호 안. 예: `(혼잣말)`, `(겨우)`, `(E. 작게)`, `(O.S.)`
- **3행**: 대사 본문. 들여쓰기 4칸. 마침표·말줄임표 자유.

**평탄 포맷(디지털 공유용) 허용:**
협업 가독성이 우선이면 `인물명: 대사` 한 줄 형태도 허용. 단 회차 전체 통일.

```
지수: ...오늘 밤 비 온대.
```

**금지 패턴:**
- `이름: ` 형식 안에 마크다운 굵게(`**이름**: 대사`) 금지
- 한 인물의 연속 발화 시 인물명 생략 금지 — 매 발화마다 명시

## 인물명 표기 — 방송 작가실 표준

지문 안에서 인물을 언급할 때:
- **평문 사용** — `유하이가 들어온다` (NOT `**유하이**가 들어온다`)
- 처음 등장 시: `유하이(20세, 트레이닝복)`처럼 나이·외형을 괄호로 한 번만
- 인물 부재의 시각화 — `(인서트) 시아의 의자. 비어 있다.` 같이 인물명은 평문

## 약속 기호 — 한국 방송 표준 (전체)

| 기호 | 의미 | 예시 |
|------|------|------|
| `(E.)` | 효과음·이펙트 (작게·크게·메아리 등) | `(E. 멀리서) 사이렌 소리` |
| `(F.)` | Filter — 전화·확성기·인터컴 등 매개 음 | `(F.) 김 PD, 지금 어디야?` |
| `(V.O.)` | Voice Over — 화면 밖 인물 내레이션 | `지수(V.O.) 그날 밤, 나는...` |
| `(O.S.)` | Off-Screen — 같은 공간 안 화면 밖 인물 | `(O.S.) 들어와.` |
| `Na.` | 나레이션 (서술자) | `Na. 도시의 새벽은 잠들지 않는다.` |
| `(C.U)` | Close-Up | `(C.U) 시아의 손.` |
| `(Big C.U)` | Big Close-Up | `(Big C.U) 그녀의 눈.` |
| `(롱샷)` | Long Shot | `(롱샷) 두 사람이 마주 앉아.` |
| `(부감)` | High Angle | `(부감) 한강이 펼쳐진다.` |
| `(앙각)` | Low Angle | `(앙각) 건물 외벽이 솟는다.` |
| `(인서트)` | Insert (삽입 컷) | `(인서트) 시계 — 03:42.` |
| `(컷)` | Cut to next | `(컷)` |
| `(F.O)` / `(F.I)` | Fade Out / Fade In | `(F.O)` |
| `F.B` 또는 `(회상)` | Flashback | `S#42. ... / (F.B — 7년 전)` |
| `(꿈)` | Dream sequence | `S#N. ... / (꿈)` |
| `M.` | Music — 음악 큐 | `M. 메인 테마 인트로 — 15초.` |
| `S.E.` | Sound Effect | `S.E. 문 닫히는 소리.` |
| `자막:` | 화면 자막 | `자막: 6개월 後` |

## 씬 사이 구분 — 표준

씬이 끝나면:

```
   (컷)

S#13. 다음 장소 / 시간 / 화면종류
```

- 마지막 줄: `(컷)` 또는 `(F.O)` 또는 (대사·지문 후 자연 종결)
- 한 줄 빈 줄
- 바로 다음 씬 헤더
- **마크다운 `---` 절대 금지**
