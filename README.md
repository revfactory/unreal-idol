## 작성 방식 — V4 페르소나 병렬 대화 아키텍처

본 프로젝트는 *단일 작가가 모든 인물 대사를 쓰는 평면적 대화*를 해소하기 위해 다음 분업 구조를 채택했습니다:

```
[기획] showrunner → plot-architect → character-designer

[회차 작성]
  scene-director (씬 분해)
    ↓
  action-writer (지문 전담, 대사 0줄)
    ↓
  dialogue-conductor (15명 페르소나 병렬 호출)
    ├── persona-yuhai (유하이)
    ├── persona-minseorin (민서린)
    ├── persona-charoa (차로아)
    ├── ... (인물별 페르소나 15명)
    ↓
  script-assembler (지문 + 대사 조립)
    ↓
[검수]
  dialogue-coach (대사 밀도)
    → script-formatter (방송 표준 포맷)
    → script-naturalness-reviewer (OpenAI Codex CLI 외부 검수)
    → continuity-editor (최종 게이트)
```

**핵심 혁신**:
- 각 인물에게 자기 voice를 가진 페르소나 에이전트 배정
- 같은 씬에 등장하는 인물들의 페르소나를 *병렬 호출*해 *실제 사람의 대화*처럼 직조
- Claude 1차 산출물에 OpenAI Codex(GPT-5.1)의 외부 시각으로 한국어 자연스러움 검수

자세한 내용은 [HARNESS.md](HARNESS.md) 참고.
